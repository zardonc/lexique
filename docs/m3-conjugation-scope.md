## 已确认的范围

- 离线变位资源随分发包提供，独立于用户学习数据。
- 每个动词提供下述约定矩阵的完整变位表，每个语式／时态单独一个区块。
- 动词信息显示英文译义、传统变位组别和助动词。第一组为规则 -er 动词；第二组为 finir → finissons 一类规则 -ir 动词；第三组／不规则包含其余动词，包括 aller、partir。
- 下列七个时态区块默认按列表顺序置前，并显示重点标识；其他区块继续可见。重点标识与查询匹配高亮分别呈现，非重点区块内的全部匹配同样高亮。
- 存在多个合法助动词时，动词信息显示所有适用助动词及简短用法解释；受影响时态区块显示有明确标签的备选形式。代词式使用自身适用的助动词及配合规则。
- 支持普通主动式及代词式，例如 laver / se laver；被动、否定句和疑问句转换留待后续。
- 覆盖准入资源中所有可用动词，不人为缩成固定的高频词数量；错误记录排除和修订须有依据、可追踪。
- 缺陷动词保留实际不可用格，不编造完整表；资源缺项明确报告。
- 主流程为输入词形 → 识别全部候选动词 → 进入表格并高亮全部匹配。只有一个候选时直接打开；多个候选时显示英文译义和匹配数供选择，其他候选在进入表格后仍可访问。
- 查询支持单一形式和完整动词表达，可带主语代词，例如 sommes、avons aimé、se laver、je me lave；按完整输入识别全部合法解释，不拆成独立单词后冒充整个表达的匹配。任意句子分析留待后续。
- 有限式行显示主语代词及完整变位，代词式显示适用的自反代词；命令式及非限定形式按各自形式呈现。
- 提供三种动词着色模式的切换控件：完整动词部分（含助动词）、仅实义动词、仅实义动词的变位字符。各模式的主语／自反代词保持普通文字颜色，查询匹配采用独立高亮。
- 三种模式以 nous avions lavé 为例：模式 1 给 avions lavé 着色；模式 2 仅给 lavé 着色；模式 3 仅给 lavé 的 é 着色，avions 保持普通颜色。模式 3 对 lavais 仅给 ais 着色，对整个第三组／不规则类别不作动词着色，即使其中某个形式有可识别词尾。模式 1／2 的适用范围不因此改变；模式 3 的规则动词字符边界须有验证。
- 默认着色为模式 3，所选模式全动词共用，在当前设备跨重启保存。模式 3 中不规则动词保持普通颜色，仍可切换为模式 1／2；查询匹配高亮不受动词着色模式影响。
- 行内同时显示适用的性别异体，例如 je suis allé / allée；过去分词区块提供经过验证的性数形式。依赖句子语境的配合使用参考形式及简短说明，不仅凭动词及主语猜测；avoir 的前置直接宾语配合属于此类。
- 动词信息和歧义候选显示简短英文译义，必要时带简短义项标签。缺英文译义时明确标记，仍可查看已有变位，不编造译义或隐藏可用动词。
- 查询忽略大小写，接受 Unicode 等价拼写、直／弯撇号，以及首尾和重复空白；保留重音区别，不通过去重音或拼写猜测冒充精确匹配。展示保留正确法语拼写。
- 用户自定义区块顺序全动词共用，在当前设备跨重启保存；提供恢复默认。重点时态的身份不随区块移动改变，恢复默认时重建七个重点时态置前的顺序。
- 每个展示形式提供按需播放，朗读完整表达及其展示的代词，复用已有声线及正常／慢速偏好。性别和拼写备选形式可分别播放；播放错误明确显示。
- 词典与变位入口使用同一动词视图，并提供双向跳转。
- 表格顺序可调整；同一形式的全部原形、人称、时态匹配及同格合法异体均保留。

## 约定语式／时态矩阵

表中每一项单独形成一个区块，共 23 个区块；重点时态按上节规则置前。

| 类别 | 区块 |
| --- | --- |
| Indicatif | Présent、passé composé、imparfait、plus-que-parfait、passé simple、passé antérieur、futur simple、futur antérieur |
| Conditionnel | Présent、passé |
| Subjonctif | Présent、passé、imparfait、plus-que-parfait |
| Impératif | Présent、passé |
| Infinitif | Présent、passé |
| Participe | Présent（aimant）、passé（aimé）、composé（ayant aimé） |
| Gérondif | Présent（en aimant）、passé（en ayant aimé） |

文学形式包含在该矩阵中。历史名称 conditionnel passé deuxième forme 在对应虚拟式形式旁解释，
不重复创建相同词形集合。双重复合式（surcomposés，例如 j'ai eu aimé）留待后续扩展。

## 默认呈现约定

以下落地默认值已随整份范围确认：

- 七个重点时态之后，其他区块按矩阵的类别及列出顺序排列，已置前的区块不重复显示。
- 候选按法语原形稳定排序；同原形的不同用法保留可辨别的标签。候选数和匹配数分别表达，不把一个动词的多个人称匹配误当成多个动词。
- 无匹配时明确显示缺项并保留查询输入；资源读取或生成失败显示错误，不伪装成无匹配。
- 经验证的缺陷／不适用格与尚缺数据的格采用不同文字状态；空格不自动补齐，不把资源缺项断言为语法上不存在。
- 重点标识、动词着色和查询匹配相互独立；颜色之外保留可辨识的标识／文字，适用于既有主题和键盘操作。
- 查询、浏览和播放不会自动创建或改写生词记录、笔记或复习进度；从词典进入的保存继续遵循已有明确保存规则。

## 首次验收目标

Windows x64 为 M3 变位首个验收目标，不以其他平台实机验收阻塞本期目标。
其他平台执行及四目标正式发行继续分别验收，不能从 Windows 结果推导通过。

- 从全新开发交付、备齐已声明运行依赖和语音资源后首次断网启动，完成词形及表达反查、候选切换、完整约定表展示和按需发音。
- 对规则／不规则、助动词、代词式、缺陷、多助动词、异体、多人称／多时态及多个原形样例，保留输入、独立期望、实际表和全部匹配标记。
- 验证查词与变位的双向跳转、三种着色及不规则排除、重点时态与匹配高亮独立，以及正常退出／重启后顺序和着色偏好恢复。
- 缺失／损坏资源、缺译义、未收录表达和语音失败保持可见；失败保留既有学习数据和可用内容。
- 覆盖约定矩阵的实际生成与语音样例，保留可重跑入口和对应版本身份；完成产品代码所需的前后端及浏览器／原生检查。

## 实施前置验证

以下是工程与资源工作，不是交给用户补充的产品问题：

1. 核验英文译义、组别、助动词、代词式及配合所需数据的来源、许可和覆盖。
2. 验证 23 区块对应的源读取／组合生成，区分真实缺陷、语境要求与数据缺项；保留变体和来源，不以未验证补格冒充完整覆盖。
3. 为第一／第二组验证模式 3 的字符边界，不能只用字符串差异猜词尾；第三组完全排除该模式的着色。
4. 验证完整表达反查及已确认的输入等价规则，避免把不同表达或去重音形式混成同一精确匹配。
5. 验证正常／慢速完整形式的生成、实际播放和代表性法语发音质量；复用既有平台、主管及缓存边界。
6. 测量完整资源、索引和首次／后续查找成本，并在实施规格中给出有实测依据的验收预算；本范围不编造延迟或包体承诺。

## 语法资料，供矩阵与配合规则确认

- [Académie française 的 aimer 变位表](https://www.dictionnaire-academie.fr/conjuguer/A9A1016)提供直陈式、条件式、虚拟式、命令式及非限定形式的参考。
- [Usito 的语式／时态表](https://examen-francais-quebec.usito.usherbrooke.ca/articles/th%C3%A9matiques/contant_1)分别列出标准形式、副动词及罕见的双重复合式；双重复合式不是文学时态的同义词。
- [OQLF 对条件式过去与虚拟式愈过去的说明](https://vitrinelinguistique.oqlf.gouv.qc.ca/24141/la-grammaire/le-verbe/temps-grammaticaux/conditionnel/conditionnel-passe-et-plus-que-parfait-du-subjonctif)说明历史名称 conditionnel passé deuxième forme 对应虚拟式愈过去形态的条件用法，不能当成独立的新词形集合。
- [OQLF 的简单式／复合式对照](https://vitrinelinguistique.oqlf.gouv.qc.ca/24658/la-grammaire/le-verbe/temps-grammaticaux/temps-simples-et-temps-composes)与其他参考的分词命名存在差异；正式名称须同时指明实际构造，如 ayant aimé。
- [加拿大政府的 avoir 过去分词配合规则](https://nos-langues.canada.ca/fr/cles-de-la-redaction/participe-passe-avec-avoir)指出前置直接宾语影响性数配合，不能仅按动词原形及主语人称确定。

上述资料用于界定产品承诺，不证明现有 Lefff 数据或生成程序已达到对应覆盖。
