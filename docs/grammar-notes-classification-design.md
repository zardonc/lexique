# 语法笔记与学习分类

语法记录与学习分类属于用户学习数据。本功能扩展桌面应用的笔记组织与语法学习能力，不依赖 D2 全量词库内容完成。

## 已确认行为

- 一个语法知识点对应一条独立的语法记录，具有自己的身份，可以单独创建、编辑和用于复习。
- 首期学习分类只有一层，不建立父子分类。
- 同一份记录可以归入多个学习分类；从任一分类访问的是同一份内容。
- 生词记录和语法记录共用一套学习分类。
- 记录可以不选分类并正常保存；未分类记录可从“未分类”筛选中找到。
- 分类列表初始为空，由用户自行创建；已有记录保持未分类。
- 分类名称唯一；重命名保持分类身份和全部记录归属。
- 删除分类只解除相应归属，保留记录、复习卡片与学习进度；失去最后一个分类的记录成为未分类记录。
- 语法记录使用必填标题与可为空的自由正文，规则说明、例外和例句可写在正文中；分类独立选择。
- 每条语法记录首期最多对应一张文字问答卡，题面与答案由用户手动整理；未加入复习时不建卡，卡片评分与排程独立。
- 现有“生词本”入口扩展为“笔记”，内部提供“生词／语法”页签，两种记录共用分类列表。
- 语法正文采用多行纯文本，完整保留换行。
- 语法标题可以修改或重名；重名不自动合并或覆盖记录。
- 首次加入语法复习时，标题与正文复制到题面、答案的可编辑草稿；题面和答案均完整后，用户明确保存并加入。
- 已保存的问答卡内容独立于笔记标题和正文，后续笔记修改不自动覆盖问答卡。
- 语法笔记和问答草稿均明确保存；有未保存修改时，切换记录、页面或正常退出提供“保存／放弃／留下”。保存失败保留当前输入，未保存草稿不跨重启保留。
- 编辑已有问答卡的题面或答案仍保留原卡片身份、到期时间、排程和评分历史。
- 语法问答卡进入现有复习队列，与生词卡共用每日额度、学习日、评分、暂停／恢复和评分撤销规则。
- 删除语法记录前明确确认将永久删除的内容；删除记录及其分类归属、关联问答卡、学习进度和评分历史，保留其他记录与分类。
- 首期通过暂停／恢复保留语法问答卡与学习进度，不提供独立删除问答卡或清空进度的入口。
- 编辑记录的分类归属与语法标题／正文或生词笔记一起明确保存；放弃编辑撤回分类选择，保存失败保留全部输入。
- 当前页签选中的多条记录可批量添加或移除某个分类，保留各自已有的其他分类；点击批量操作按钮后保存并逐条反馈结果，失败项可单独重试。
- 分类名称去除首尾空白后保存，同一文字的等价编码和大小写视为同名，重音区别保留；显示名称保留用户输入的大小写。
- 首期一次筛选一个分类，提供“全部／未分类”，并与生词／语法页签和关键词搜索组合；多分类记录在任一所属分类下均可找到。
- 删除已评分的语法记录不返还其已经消耗的当日新卡／复习额度；笔记、卡片和评分历史仍按删除规则移除。
- 若全局最近一次评分属于被删除的语法记录，清除这次撤销机会，直到产生新评分；不自动改为撤销更早评分。最近评分属于其他记录时，保留其原有撤销状态。
- 语法列表搜索标题与正文，忽略大小写和重音；独立问答卡的题面／答案首期不进入笔记搜索。
- 语法列表提供标题、创建时间、更新时间和下次复习时间排序，默认最近更新在前。
- 生词与语法分别保存排序偏好；重启回到生词页签、全部分类、空搜索，清除多选和当前打开记录。
- 首期学习分类用于笔记整理、搜索和筛选，复习使用共用队列；按分类启动复习留待后续需求。

## 字段与列表规则

沿用现有纯文本字段的校验方式和字符计数，采用以下限制：

| 字段 | 内容与限制 |
| --- | --- |
| 语法标题 | 必填单行文本，去除首尾空白后为 1–200 个 Unicode 码点 |
| 语法正文 | 可为空的多行纯文本，最多 20,000 个 Unicode 码点，完整保留换行 |
| 问答卡题面、答案 | 分别为必填多行纯文本，各最多 20,000 个 Unicode 码点，不接受仅含空白的内容 |
| 分类名称 | 必填单行文本，去除首尾空白后为 1–200 个 Unicode 码点，按已确认规则判重 |

先保存语法记录，再从已保存的标题／正文生成问答草稿；笔记与卡片分别明确保存。分类列表按名称升序排列；分类创建、改名和删除通过共用分类列表明确执行，记录编辑页的分类归属随记录保存。

语法标题、创建时间和更新时间各提供升序／降序，下次复习时间较早优先。下次复习时间取已学习语法卡的原始到期时间，未学习的卡片随后，未加入复习的记录最后；暂停和每日额度不改写原排程。改变页签、分类或搜索范围时清空多选，排序变化保留多选；删除当前筛选分类后回到“全部”。

## 备份与交付范围

扩展既有学习数据备份，完整包含语法记录、分类及归属、问答卡内容、进度、评分、队列、暂停状态、各页签排序偏好，以及删除后保留的已用额度与撤销状态。恢复保留记录和分类身份，同标题语法记录仍是独立内容。

继续读取实际已支持的旧快照版本 1／2，缺少的语法与分类数据视为空；恢复沿用既有整份确认替换、原数据副本保留与失败回退流程。恢复预览展示语法记录及分类数量，包括旧备份中的零数量。

采用保留既有学习数据的增量迁移；生词的身份、两类卡片与原有进度保持。删除语法记录只保留维持已用额度、撤销和保存重试规则所必需的用量／状态，包括失效保存操作编号，不保留被删除记录的内容和评分详情。批量分类整理和删除均处理重复请求、编辑冲突及失效记录引用，失败保留可见错误和当前输入。

删除后新建记录、分类或卡片使用新的身份；备份恢复也保留这一关系，旧请求不能作用于新建对象。

首期交付范围为 Windows x64 桌面应用与既有浏览器／WASM 验证边界。分类层级、独立删除问答卡、按分类复习、同步、通用导入导出、Markdown 编辑器和新资源／服务接入不属于本期。

## 验收场景

- 两条同标题语法记录分别保存、编辑并重启恢复；正文换行和空正文完整保留。
- 同一记录从多个分类访问时始终显示同一份内容；分类改名保留归属，删除分类保留笔记、卡片与进度，失去全部分类的记录能从“未分类”找到。
- 首次加入语法复习可编辑复制出的问答草稿；题面或答案为空时不能加入，保存失败保留输入；后续笔记修改不覆盖问答卡，卡片内容修改不重置进度。
- 未保存修改的切换和正常退出提供离开保护；放弃修改后恢复已保存内容，未保存草稿不跨重启保留。
- 语法卡与既有生词卡混合复习，验证共享额度、暂停／恢复和跨重启评分撤销；语法内容和分类整理保留既有生词学习进度。
- 删除语法记录前展示完整影响；确认后移除该记录的全部关联学习状态，其他记录和分类仍可正常访问与复习。
- 单条记录的分类归属与内容一起保存或放弃；保存失败保留两者的输入，不能只提交其中一部分。
- 批量添加／移除分类只调整指定归属，保留其他归属；部分失败逐条展示真实结果，重试不覆盖记录正文或重复创建归属。
- 分类名称首尾空白、大小写和等价编码不能产生重复分类，重音不同的名称仍可分别创建；按分类、记录类型和关键词组合筛选得到一致结果。
- 删除已评分记录后，当日已用额度保持；删除最近评分对应的记录后，重启也不能撤销更早评分；其他记录原有的撤销能力保持。
- 语法标题／正文的大小写和重音搜索得到相同匹配；排序偏好分别跨重启保存，页签、分类筛选、关键词和选择状态按规则重置。
- 字段空白、单行限制与字符上限在界面、IPC 和存储边界一致校验；正文及问答卡换行完整保留。
- 从既有用户库升级后，原生词、卡片身份及进度保持；迁移失败回滚，重复保存或删除不能恢复已删除记录或重复扣计额度。
- 删除并新建记录、分类或卡片，以及备份恢复后再新建对象时，旧的保存、归类和评分请求不能误改新对象。
- 新备份恢复语法、分类、归属和全部复习状态；旧备份照常恢复，缺少的新部分为空。恢复后验证查词、编辑、分类整理和已保存请求重试，保留既有词头的 Unicode 等价身份与用户文本。

实现后按 [README](../README.md)运行 lint、typecheck、build、Rust 格式与编译检查；先执行 `pnpm rust:test:build`，再执行保留硬性 60 秒超时的 `pnpm test:rust`。选择覆盖上述流程的 Playwright 检查，并用真实 SQLite 与 Windows 原生链路验证保存、重启、复习及备份恢复。

上述行为已接入现有笔记、复习和备份链路，执行结果见[验证记录](verification.md#语法笔记与共享分类)。文档检查与浏览器预览不能替代原生持久化验收；其他平台、安装包和正式发行仍按既有准入门槛分别验收。

## 现有边界

领域用语见[词汇表](../GLOSSARY.md)，现有模块和持久化边界见[架构](architecture.md)，现有词汇复习规则见[M2 规格](m2-spec.md)。

当前生词记录仍遵循同词一份、只读词头和明确保存规则，识义卡与听音卡保留各自进度。语法记录的独立身份与可编辑标题不改变这些既有行为。

语法记录身份与标题的关系见 [ADR 0010](adr/0010-grammar-record-identity-independent-of-title.md)。

当前[学习快照](../crates/storage/src/learning_snapshot.rs) v3 保存生词与语法记录、分类与归属、卡片、进度、评分、队列、偏好、删除后保留的额度和撤销状态。[快照导入](../crates/storage/src/snapshot_import.rs)先校验数据，再在已初始化的空库中事务导入；整份备份恢复沿用既有暂存、确认替换和失败回退流程，继续读取旧 v1／v2。

当前[生词搜索与排序](../crates/storage/src/vocabulary.rs)匹配词头、笔记和兜底摘要，忽略大小写与重音；例句和词典原文不在搜索范围。排序偏好跨重启保留并进入备份；关键词、当前打开记录和多选状态不跨重启保留。

当前[额度与评分撤销](../crates/storage/src/review.rs)从有效评分历史和删除后聚合保留的用量计算已用额度，撤销检查全局阻断状态及最后插入的评分。[快照校验](../crates/storage/src/snapshot_validation.rs)要求评分、进度及队列中的记录／卡片引用有效；语法删除同步维护这些引用和全局状态。
