# 架构与开发边界

2026-11-05，当前共享 schema 为 17。`QueueCache` 从短读快照批量读取 progress／设置／额度／位置，随后按持久修订日志只加载普通进度、音频及位置变更涉及的行；初次读取、上下文／集合改变及超过 1,024 条保留日志时重建元数据。必要日切／位置变更进入短立即事务，修订在该事务内取得，提交后更新缓存，避免自身位置写回造成下一次重建。SQLite `data_version` 变化触发有限重读，持续竞争返回真实错误；持久队列修订与连接的 `data_version` 分工明确。

桌面 `WindowValidator` 持有一个元数据缓存、两个固定文件校验 worker、最多八个在途 probe；从前 50 个候选中返回最多四张可展示卡，压缩字节缓存／响应上限 32 MiB，等待起点 75 ms。文件 worker 不持数据库连接；等待后重新计算已提交资格及选定版本，不再追加 probe 批次。IPC cursor 携带上次修订及最多四张卡的指纹，响应分别返回变更项、移除 ID、顺序和总准入摘要；未改变的条目与字节省略，修订缺口明确返回全窗口。前端保留当前 presentation，并可在评分成功后先提升已加载下一卡，再补窗口。窗口外 readiness 仍仅代表候选。Windows x64 本期实现、性能及生命周期证据见[实施记录](evidence/issue-24/continuation-2026-11-04.md)与[验收清单](evidence/issue-24/acceptance-matrix-2026-11-05.md)。

schema 12–15 增量接入选定内容、后继执行、幂等更换操作及统一生命周期。内容版本和新发布的物理 locator／hash 与合成规格键分开；不同生词可共享一份已验证版本，归属不依赖卡片。平台先持久登记 intent，再发布独立不可变实例并安全回读，条件完成来源及选择；旧执行不覆盖新意图。当前、上一版／孤儿期限、迁移及发布保护统一由 `audio_version_protection` 仲裁。迁移 15 按 SQLite 父表重建流程，在 BEGIN 前关闭外键，事务内重建并检查外键，提交／回滚后恢复 enforcement；不降级或重建用户库。

schema 16 保存队列修订日志，schema 17 保存自动修复去重身份及窗口／本日／批量需求类别。近期及本日实际额度准入的缺词音频按原已知规格修复；未知 legacy 例外有三语提示，终态不随刷新重启。规划不写位置／额度／进度，不主动创建未来全库需求；主管每轮处理最多 16 个计划，后台每四个窗口任务服务其他需求，另有 30 秒老化及独立 P0 槽。首次旧音频登记仍按最近修改词每批 16 项后台执行。

```text
React / TypeScript
    └─ RuntimeAdapter（注入）
        ├─ 浏览器：明确报告预览，不冒充本地存储
        └─ 桌面：Tauri invoke → Rust → SQLite

Rust core → 同一 FSRS 调度入口 → 原生 / wasm32-unknown-unknown
Rust storage → 注入 SQLite connection → 事务迁移
```

## 当前模块

| 位置 | 职责 | 禁止混入 |
| --- | --- | --- |
| `apps/desktop/src` | 页面壳、主题、本地化、交互状态 | 原生文件操作、真实凭据 |
| `src/platform/runtime.ts` | Tauri IPC 与 Zod 响应校验；显式浏览器预览 | 假成功、吞掉 IPC 错误 |
| `apps/desktop/src-tauri` | 平台路径、应用启动、命令装配 | UI 状态与未授权的远程内容 |
| `crates/storage` | SQLite 迁移、生词记录、双卡身份、评分进度与历史、幂等操作及搜索排序 | 字典资源更新覆盖用户库 |
| `crates/dictionary` | 固定资源 SHA-256 校验、只读内存快照查询、TEI 解析为纯文本 | 用户库、网络、原始 HTML 执行 |
| `crates/core` | 可移植 Rust / WASM、固定 FSRS 与日历学习日调度 | 文件系统、Tauri、SQLite、令牌 |

首个迁移创建 `app_metadata`；第二个迁移增量创建生词记录与已提交保存操作。NFC 标准词头唯一约束与立即事务防止并发副本；操作编号绑定原请求，在响应丢失后返回当前记录且不重放写入；修订号检查和更新在同一事务中完成。收藏时摘要与来源为只读 JSON，独立笔记另列保存。只保存已提交操作，不持久化草稿。第三个迁移创建 `review_cards`，以生词记录和卡片类型的唯一约束及立即事务实现幂等双卡创建；不复制生词内容、不重建已有卡片。第四个迁移创建 `review_progress` 和 `review_ratings`：评分在立即事务中检查修订号及资格，保存评分前状态、请求、调度结果、学习日和额度类型，并更新卡片进度；相同操作重试返回已保存结果，不重复计数。后续 M2 迁移已接入完整队列、一级撤销、暂停／自动加入、共享例句和排序；schema 11 接入持久批量／CPU 语音任务，schema 12–17 接入上述内容版本、生命周期、队列修订和修复需求。分类和同步仍未实现。用户库与资源库独立；遇到更高 schema 立即报错，禁止降级重建；迁移失败回滚且不提高版本。

#15 通过受限 `review_add` / `review_cards` 与 `speech_generate` / `speech_cached` 命令接入同一 `RuntimeAdapter`。ID 必须为正且处于 JavaScript 安全整数范围，响应由 Zod 校验；这些命令合成读取用户库的词头和语音偏好，不接受前端传入路径或模型。Windows 适配器用固定的本地 Python 运行库执行内嵌 worker，校验七个模型资源哈希，生成目标 48 kbit/s 的 Ogg Opus。合成失败保留已提交两卡和旧音频，响应丢失后的再次加入仍保持身份。听音卡使用内存音频副本，播放请求取消与对话框生命周期绑定；成功重播清除失败状态，翻面不再次播放。#16 通过 `review_progress`、`review_availability` 和 `review_rate` 命令接入评分及其持久化；听音卡本次未成功播放时不能评分。

词典和生词详情的测试播放按钮使用 `speech_preview`：限制非空、最多 200 个 Unicode 字符且无控制字符，读取已保存的声线及语速，通过应用拥有的 CPU 主管先读有效缓存、再投递有界交互需求。临时查询内容按生成完成时间保留七天，不创建生词或复习卡、不改变进度；保存单词后现有选定内容优先。前端显示合成语音标识及真实失败信息。该入口不代表完整词典或正式发行已验收。

M1 请求由 Rust 严格反序列化，前端请求 / 响应由 Zod 校验。标准词头最多 200 个 Unicode 标量且无控制字符，独立笔记最多 20,000 个标量；保留笔记原样，组合重音不作自动合并。新记录的来源和摘要在平台层重新查询已校验词典生成，IPC 不接受前端提供的来源或摘要。逻辑引用保留源查询拼写，避免 NFC 身份归一改变现有精确查询。搜索独立采用 NFD 去组合音标及小写后的字面子串；排序同值时使用稳定身份打破平局。

原生数据命令在阻塞任务中重新打开已初始化用户库（不在库丢失时静默新建），读取错误保持可见。窗口正常关闭先阻止默认退出，再通知 React；明确选择保存并得到成功确认、放弃，或当前没有未保存修改时才调用受限 `finish_close` 销毁窗口。macOS 菜单 Quit / Cmd+Q 替换为同一路径；macOS Dock Quit 的框架终止路径尚未覆盖，须在该平台验收前解决。main 窗口仅新增生词命令、事件监听和完成关闭权限，不开放文件系统、shell 或网络插件。

状态命令只读且无外部输入；查词命令只接受 1–512 UTF-8 字节的无控制字符查询，保留原始拼写，不接受路径。通过应用命令清单自动生成权限，仅授权本地 main 窗口。未开放文件系统、shell、HTTP 插件或远程窗口。IPC 响应用 Zod 校验；SQLite 初始化错误保持原始错误链，不转换成成功。只有框架边界创建平台资源，存储逻辑接收 connection。

原生构建用 Python 标准库从已准入源包生成 SQLite，并附带来源、原始源包和许可；构建前验证已有生成物，损坏则失败。运行时由平台层解析 `dictionary/dictionary.sqlite3`，每次查询校验构建时固定的哈希，再反序列化同一批字节为只读 SQLite 快照，避免资源被并发替换时读取未验证内容。`entries.key` 采用二进制完全匹配与参数化查询，同键记录按源序排列；TEI 仅解析为 React 文本，不执行标记。缺失、损坏、查询失败与无结果分别返回。用户库路径、schema 及迁移完全独立。

## 后续模块放置

变位查询复用 `RuntimeAdapter` 和 `lexique-dictionary` 资源 crate，通过仅授予本地 main 窗口的 `conjugation_lookup` 读取固定 `conjugation/conjugation.sqlite3`；请求只接受 1–512 UTF-8 字节的非空、无控制字符原始词形，不接受路径。构建时验证格式 2 的资源并固定摘要；运行时与词典共用校验字节、只读 SQLite 快照和参数化查询，返回全部候选的源格与元数据，前端用 Zod 校验身份和结构。此命令不打开用户库。前端按法语词元排序并独立计算候选数和逻辑匹配格数，保留源拼写、标签及不确定状态；不生成复合／代词式表达或根据缺词形推断语法缺陷。两种资源通过构建入口与 portable 打包一起放到可执行文件旁，保留各自许可及对应源码。见 [#40 证据](evidence/issue-40/README.md)。

#13 在共享核心提供 `scheduling::schedule` 及严格 JSON 入口 `schedule_json`，接收卡片、评分、Unix 秒时间与 IANA 时区，不读取设备时钟。输出记忆状态、阶段、完整步骤秒数或取整天数、绝对到期时间、经过学习日、模型参数和时区库版本；调用方须保存完整请求和结果作为历史，不以最新设置重建旧请求。固定 FSRS 6.6.2 的标量调度数学使用显式 vendored 兼容补丁，统一调用关闭默认 features 的 libm 0.2.16；公式、官方参数、步骤及取整不变。历史标识 `fsrs-rs/6.6.2+libm-0.2.16` 与未修改上游包区分，拒绝混用。Windows x64 native / 实际 WASM 对照通过，其他平台实际执行另验。此票不迁移用户库、不添加 IPC 或评分 UI。原生 CLI 与 WASM 的有界输入缓冲区调用同一 JSON 入口；缓冲区 ABI 为同步调用，下一次请求使旧指针失效。详见 [#13 验证](evidence/issue-13/README.md)。

| 能力 | 建议实现位置 | 先决条件 |
| --- | --- | --- |
| 词典 / 变位资源 | 独立 Rust crate + 桌面资源适配 | 许可、数据格式、覆盖集与 HTML 隔离 |
| FSRS | 可编译 WASM 的纯 Rust 核心 | 算法实现 / 参数确认与跨端固定样例 |
| TTS / 音频 | 桌面平台适配，按需独立 crate | 模型许可、法语质量、四架构验证 |
| 凭据 / OAuth | 桌面系统凭据库；Web 经 BFF | 权限、回调、访问控制与刷新策略 |
| 同步 | 业务写入事务内 outbox；独立协调逻辑注入网络 / 存储 | 身份、连续 frontier、因果冲突 / 删除、来源认证、检查点与可验证 GC |
| Web 复习 / BFF | 第二阶段新增应用，复用已验证核心 | WASM 真正调度、认证、限流和 CSRF |

暂不创建空 BFF 或假接口。当前没有 HTTP 服务，无需为了骨架引入账户、端点或密钥。未来新增端点必须同时带输入 schema、鉴权、限流与适用的 CSRF 防护。外部词典 HTML 不可直接渲染或获得原生权限。

2026-11-02 同步规划：桌面继续使用 `crates/storage` 的真实业务事务，在同一次提交中保存稳定操作、replica / seq 与 durable outbox；收到的操作与去重回执也原子应用且不再次发出。同步协调器通过已有平台边界处理 JSONL 封存、最后发布 JSON 清单、批量重试和冲突，不把云 API、路径或令牌放进纯调度核心。SQLite 文件 / WAL 不直接交给云盘客户端热复制；快照来自一致视图。此处描述待接入边界，不表示已经增加迁移、crate 或网络权限。

M6 推荐 IndexedDB 宿主将业务、outbox、序号及回执在同一事务中持久提交，完成后才确认；实际 WASM 只计算固定输入，不代替存储。多标签页通过事务分配身份及检查修订，网络任务限频并可恢复。服务特有的对象 ID / ETag / delta 位于 Drive / OneDrive 适配器，不能假定跨服务全局锁。检查点、成员 / epoch、GC、密钥与恢复准入详见[同步设计](sync-design.md)；当前 `RuntimeAdapter` 浏览器路径仍报告预览，尚无上述存储或同步实现。

## 配置与发行

语音偏好通过受限 `speech_preferences` 命令读取／保存，沿用 `app_metadata` 中单条 JSON；偏好本身不提高 schema 版本。Rust 枚举及前端 Zod 严格限制声线 `female`／`male`（兼容读取旧 `siwis`／`tom`，保存使用新值）和语速 `normal`／`slow`。未知字段、非法响应和损坏配置保持错误，不覆盖为默认值；只有配置不存在时使用女声／正常默认值。新生成语音读取当前声线；播放读取当前正常 / 0.6 倍速偏好。修改偏好不重写既有音频或卡片；缺失或失败音频可通过再次加入重试。

2026-10-26 确认的发行要求：四个平台 / 架构各提供内嵌模型的完整版和不内嵌模型的 Lite 版。Lite 在用户通过“额外资源”明确发起后下载模型，完成并验证后方可离线合成；缺失或下载失败须显示真实状态。下载实现须固定可信来源、版本及校验值，限制文件大小和解压路径，并先暂存验证再安装，不覆盖学习数据；Windows portable 的下载资源仍须位于 `Lexique-data/`。完整版须避免保留无谓的模型副本。以上是待实现要求，并不表示已开放网络权限、完成模型准入或具备 TTS。

Windows 的 `tauri.windows.conf.json` 通过 Tauri `appDirectoriesOverride` 将五类应用目录定位到可执行文件旁的 `Lexique-data/`；WebView 未设置独立 `dataDirectory`，由框架继承被覆盖的 local-data 路径。入口在启动框架线程前将子进程继承的 `TEMP` / `TMP` 定位到同一目录下的 `temp/`，并固定 `WEBVIEW2_USER_DATA_FOLDER` 到 `webview/EBWebView/`，避免继承的外部路径覆盖框架设置。用户库、WebView profile、配置、日志和临时文件因此随目录移动，不依赖启动工作目录。不可写时保留失败，不回退系统目录；原 AppData 内容保持原样。操作系统自身的事件日志、预取和安全软件记录不由应用控制。

产品语音生成使用 `Lexique-data/temp/speech/` 专用目录。应用拥有的独立维护 worker 在启动、成功发布及每六小时维护，GC 每批最多 100 个精确版本，目录对账保留安全 iterator、每步最多 200 项；有剩余工作时继续短批次。删除失败保存版本／mark generation 和错误，当前 sweep 继续经过其他项，下一轮重试；正常关闭停止并 join 该 worker。短事务只计算一次容量，已标记待删除字节也计入计划，达到 200 MiB 软目标便停止额外临时淘汰。文件删除／扫描不在合成 actor 或用户库写事务内进行。

统一保留规则见 [ADR 0008](adr/0008-selected-word-audio-content-versions.md)：当前选定永久、每词上一版十四天、最后归属解除七天、临时完成起七天，容量不能打断保护。访问过期即拒用，不等待物理清理。对账分别报告登记内容的逻辑字节、按安全句柄取得的文件长度／Windows 实际分配、永久／保护／可回收内容及未知文件；未完成扫描、分配测量失败与权限／重解析点失败保持可见，不删除未知文件。大小／时间不是完整性证明，使用窗口仍完整校验 SHA。macOS 路径／实机及完整生命周期按 [验证记录](verification.md) 分别验收。

Windows 缓存以能力目录句柄及 nofollow 打开目录／文件，写入和清理共用目录锁并拒绝重解析点。兼容读取保留正整数 `.ogg`；规格兼容路径与不可变新实例均使用 `s-{physical_locator}-{hash}.ogg`，新发布始终分配独立物理身份，仅管理已登记内容及应用自己的临时文件。先写临时文件并同步，再发布并完整回读校验；失败保留旧文件。播放器读取完成即释放文件句柄，播放依赖内存副本。访问时间不是有效期权威；临时期限由持久生成完成时间确定。错误写入 `Lexique-data/logs/speech-cache.log`，日志目录和文件也拒绝链接。窗口缓存、GC 竞争和持续维护的逐项运行状态见 #24 证据。

`pnpm desktop:portable` 构建 Windows x64 release 后，仅打包可执行文件、已准入词典资源、许可与使用说明，生成独立 ZIP 和 SHA-256 清单，并逐项回读校验压缩包。打包器也可对预先编译的 Windows ARM64 release 检验 PE 架构并生成独立开发样例；实际运行尚未验证。新交付必须使用空路径；不打包运行时 `Lexique-data/`，也不覆盖旧交付。当前仍依赖系统已有 WebView2，不启动安装器或首次联网下载；这不等于缺运行依赖机器、签名或完整资源发行已验收。

打包器新增成组的 `--speech-bundle` / `--speech-encoder` / `--speech-sources` 参数，仅接受 Windows x64。固定输入清单、模型 / 运行库及 Opus DLL / 源包逐项校验后，在名称带 `-speech` 的开发交付中保留资源及分别许可；输入不完整、架构不支持或校验失败时不创建新交付。最终逐文件清单与 ZIP 回读校验包含语音资源，但不因此取得 M5 完整版 / Lite 发行结论。
