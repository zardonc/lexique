# 笔记内容交换设计

2026-11-19。已确认设计；实施规格与测试计划发布为 [#183](https://github.com/zardonc/lexique/issues/183)，实现分为六个子 issue。

## 已确认范围

本期优先设计 Lexique 与外部工具之间的[笔记内容交换](../GLOSSARY.md#资源与学习数据)：笔记可以拿到外部工具阅读、整理，也可以导入外部已有笔记。包含复习进度和历史的完整学习数据备份、恢复使用已有能力，外部记录形态须兼容其保存与恢复。

首期优先兼容 Excel、Google Sheets、LibreOffice 等通用表格工具，以及 Obsidian 等 Markdown 笔记工具。

首期仅交换词汇生词记录。已有语法笔记与分类不进入交换文件；导入更新保留已有分类和其他未交换数据。

导出范围包括全部生词、当前搜索结果和当前单条记录。

## 已确认格式

- 表格交换采用 UTF-8 CSV，支持导入和导出，保留中文、法语重音、引号及多行笔记。
- Markdown 支持导入和导出；导入文件须遵循明确模板，由模板标识词头、笔记和其他交换字段。

CSV 使用词头、笔记、法语例句、中文例句四列，一条例句占一行；同词各行重复词头和笔记，导入时归为一份生词记录。没有例句的记录保留一行空例句，例句顺序沿用文件行序。

Markdown 每个词对应一个文件，批量导出使用 ZIP；导入支持单个 Markdown 文件和由模板文件组成的 ZIP。

Markdown 模板在正文显示词头、独立笔记和全部例句；笔记与例句用纯文本块保留原文，内容中的 Markdown 符号按原样显示。

CSV 规范列名可直接识别；外部表格支持在预览中手动将列映射到词头、笔记、法语例句及中文例句。

## 交换内容

交换字段限定为词头、独立笔记和笔记例句；例句保留法语与中文两侧的内容。微型兜底摘要、词典来源、复习进度、评分历史和音频不随交换文件传递。

## 导入与已有记录

同词沿用[现有标准词头规则](adr/0004-one-vocabulary-record-with-reference-digest-and-notes.md)。交换内容相同则跳过；同词内容有差异时预览，并由用户选择更新或跳过。更新保留原记录身份和复习进度，正文不自动拼接。

允许导入内置词典未收录的词，记录标明外部来源和缺少的词汇信息。外部笔记导入须有独立入口，不能受现有收藏入口必须查到内置词典的条件限制。

新记录的词头精确匹配已安装的本地词典时，自动补充词典引用和微型兜底摘要；查无结果时保留外部笔记和缺失标识。更新已有记录保留原词典信息。

本地词典缺失、损坏或读取失败时，预览展示真实错误，允许用户明确选择继续把有效内容保存为未关联的外部笔记；读取失败与未收录分别标识。

更新只作用于文件实际提供的字段：缺失字段保留已有内容，明确留空则清空；新记录缺少的可选内容为空。

例句作为一个有序列表整体更新。提供任一例句列或例句章节即替换原列表，缺少的语言侧为空；完全没有例句字段时保留原列表，明确提供空例句则清空。预览展示整组替换的内容，不按行拼接新句子和旧译文。

新导入或内容已改变的例句可先保存为未关联义项，之后在应用内补关联；已有例句原样未变时保留原关联。

导入本身只保存笔记内容。完成后由用户明确选择是否批量加入复习，不沿用普通收藏的全局自动加入设置；已有卡片和进度保留。

未关联词典的外部笔记也可手动加入识义卡和听音卡。卡背复用现有笔记、例句和缺失信息展示，例句可尚未关联义项；听音卡仍须有可用音频才能评分。外部记录在应用内可继续编辑独立笔记和未关联的笔记例句。

## 导入预览与提交

预览标明无效记录的位置和原因，允许用户排除错误记录后选择有效记录导入。最终选定的记录一次提交，保存失败时整批不写入。

CSV 同词各行的独立笔记不一致，或 ZIP 内同词 Markdown 文件内容不一致时，整个词头组标为冲突；用户修正文件或排除该词后继续导入。

## 模板约定

导出使用已保存记录的一致读取快照，范围和计数来自同一份快照，记录排序沿用生词本排序。标准 CSV 列名固定为 `headword,notes,example_fr,example_zh`，导出采用带 BOM 的 UTF-8 和逗号分隔；导入接受 UTF-8 有无 BOM，在预览中可选择逗号或分号分隔并映射列。每个目标字段最多映射一列，词头列必需。

CSV 的第一条例句对应主例句，其余行保持原顺序。字段中的引号、换行和空白按文本保留；同词笔记重复填写时须完全一致。

```csv
headword,notes,example_fr,example_zh
école,"学校；阴性名词。
常见搭配：aller à l'école。",Je vais à l'école.,我去学校。
école,"学校；阴性名词。
常见搭配：aller à l'école。",L'école ouvre à huit heures.,学校八点开门。
```

Markdown 使用固定标识 `Lexique note v1` 与规范章节名。词头必需，笔记和例句章节可省略；省略保留已有内容，提供空章节表示清空。例句按编号顺序保存，可只提供一种语言。文本围栏只用于标识边界，保留原字符串的空白、换行和反引号；导出时围栏长度长于内容中任何连续反引号序列。

````markdown
# Lexique note v1

## headword

```text
école
```

## notes

```text
学校；阴性名词。
```

## examples

### 1

#### fr

```text
Je vais à l'école.
```

#### zh

```text
我去学校。
```
````

Markdown 文件名使用适合 Windows 的可读词头及已有记录编号，避免字符替换或大小写造成重名；完整词头从文件正文取得。ZIP 中的 Markdown 文件直接读取，不将文件内路径作为学习数据或解压目标；非模板文件在预览中报告。

## 实施边界与验收

- 词头身份沿用现有 NFC 规则，保留大小写、重音和撇号区别；不按文件名、行号或外部记录编号归并。
- 导入字段沿用[词汇模型](../apps/desktop/src/platform/vocabulary.ts)的内容限制；超过词头、笔记或例句限制时报告错误，不截断。词典信息由平台读取已校验的本地资源补充，导入来源与词典来源分开保存。
- 前端负责列映射、预览和选择，通过既有 `RuntimeAdapter` 边界访问受限原生命令；文件读写在桌面平台层完成，记录和整批事务在现有 storage 模块完成。
- 提交前重新校验所选记录与预览时的修订。预览后记录已改变时整批停止，重新预览再提交；提交失败不留下半批更新。导出文件写入失败保持真实错误。
- 同时适配生词列表、详情编辑、卡背、加入复习、音频归属和相关请求／响应校验，使缺词典信息的外部记录能在现有流程中使用。已有学习数据通过现有存储机制保留。

| 验收场景 | 预期结果 |
| --- | --- |
| 中文、法语重音、引号、多行内容与反引号 | CSV 和 Markdown 导回保留交换字段的原文本 |
| 同词多条例句、单侧例句与既有上限 | 保持顺序和空侧；超限记录在预览中标错 |
| 只更新笔记、明确清空与替换例句 | 缺失字段保留，空字段清空，例句整组替换 |
| NFC 等价词头、不同重音／大小写／撇号 | 按既有身份归并，区别写法分别保留 |
| 同词差异、文件内冲突与无效记录 | 手动选择更新；冲突组可修正或排除 |
| 词典未收录、缺失、损坏或读取失败 | 外部笔记可保存，来源和错误状态如实展示 |
| 全局自动加入开启时批量导入 | 只保存笔记；之后主动加入双卡，保留已有进度 |
| 预览后有编辑、保存失败及重试 | 重新预览或整批回滚，成功重试不重复建记录或重置进度 |
| 导出写入失败、ZIP 非模板文件 | 明确报错，学习数据保持可用 |

实现后按 [README](../README.md#检查与构建) 运行相关前端、Rust、浏览器和原生文件交互检查；后端测试先预编译，执行阶段保留既有 60 秒硬限。

## 限制

CSV 经表格软件编辑和另存时可能发生类型转换，导回前须以预览中的实际文本核对；Markdown 模板提供纯文本往返。当前文件为设计，应用导入导出能力尚未实现。

笔记内容交换与[产品基线](product.md)中的导入导出目标衔接；完整备份和跨设备同步继续遵循各自的[设计边界](sync-design.md)。
