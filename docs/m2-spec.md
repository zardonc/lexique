# M2：离线词汇双卡复习、FSRS 调度、评分撤销与重启恢复

## Problem Statement

学习者已经能在桌面查词、保存生词记录并在重启后恢复，但无法把保存的内容转为真实复习。识义与听音能力需要分别巩固；没有可靠调度、离线音频、每日额度和可恢复进度时，收藏不能形成持续学习闭环。

## Solution

在既有生词本上完成“加入复习 → 识义卡 / 听音卡 → 展开答案 → 自行评分 → 排程 → 撤销 → 重启恢复”。两类卡共用生词内容、独立保留进度；提供单词离线语音、可补充例句、每日额度与下次复习时间排序。先验证固定 FSRS 候选在原生 / 实际 WASM 的一致性和语音可行性，再接完整持久化与界面。

## User Stories

1. As a 学习者, I want a 生词记录可单独加入复习的入口, so that 我能选择当前要学的词。
2. As a 学习者, I want a 批量加入及全选当前搜索结果的操作, so that 我能高效安排学习范围。
3. As a 学习者, I want a 搜索变化时清空选择、排序变化时保留选择的规则, so that 批量操作对象明确。
4. As a 学习者, I want a 默认关闭的收藏自动加入选项, so that 我能自行决定今后新收藏是否进入复习。
5. As a 学习者, I want a 不追溯旧生词且关闭不删除卡片的自动加入设置, so that 设置变化不会意外改变已有学习安排。
6. As a 学习者, I want a 同词最多一张识义卡和一张听音卡的模型, so that 不会重复建卡。
7. As a 学习者, I want a 两类卡分别评分和排程的机制, so that 识义熟练不会掩盖听音薄弱。
8. As a 学习者, I want a 重复收藏、再次加入和音频重试均保留进度的保证, so that 重试不会丢失学习成果。
9. As a 学习者, I want a 仅显示法语单词的识义卡正面, so that 我能先回忆含义。
10. As a 学习者, I want a 只提供单词语音、不显示文字的听音卡正面, so that 我能独立检验听音识词。
11. As a 学习者, I want a 听音卡进入时自动播放一次并可重播的交互, so that 我能按需要听清单词。
12. As a 学习者, I want a 展开答案时不再次自动播放的行为, so that 播放不会干扰查看答案。
13. As a 学习者, I want a 展开后显示词头、简明释义与一组法中例句的背面, so that 我能快速核对回忆。
14. As a 学习者, I want a 更多例句、独立笔记和来源信息按需展开的卡面, so that 默认信息量保持精简。
15. As a 学习者, I want a 两类卡共用且独立于笔记的例句编辑区, so that 修改内容只需保存一次。
16. As a 学习者, I want a 仅有法语或中文也可保存并标识待补例句的行为, so that 内容缺项不会阻止复习。
17. As a 学习者, I want a 明确保存、离开提醒和编辑冲突保护, so that 例句修改不会丢失或覆盖其他编辑。
18. As a 学习者, I want a 资源更新不覆盖用户内容、不重置进度的保证, so that 整理成果持续保留。
19. As a 学习者, I want a 无需联网的单词语音生成与播放, so that 断网也能完成听音复习。
20. As a 学习者, I want a 音频生成失败时仍保留两张卡、只暂时排除听音卡的行为, so that 识义学习可以继续。
21. As a 学习者, I want a 批量操作逐词显示真实结果的反馈, so that 我能只重试失败项。
22. As a 学习者, I want a 播放失败可重播或跳过的处理, so that 故障不会造成虚假评分或扣额度。
23. As a 学习者, I want a 展开答案后才出现的忘记、困难、记得、轻松四档评分, so that 我能自行评价回忆情况。
24. As a 学习者, I want a 明确说明困难表示想起但费力、未想起应选忘记的提示, so that 评分含义一致。
25. As a 学习者, I want a 固定 FSRS 默认参数驱动的长期排程, so that 复习安排可验证和重放。
26. As a 学习者, I want a 两类卡共用的目标保持率设置, so that 我能在 70%–99% 范围内按 1% 调整，默认使用 90%。
27. As a 学习者, I want a 保持率只影响后续评分的规则, so that 旧到期时间和历史不会被批量改写。
28. As a 学习者, I want a 初学与遗忘后的短期步骤, so that 需要巩固的卡片能及时再次出现。
29. As a 学习者, I want a 本地凌晨 4 点切换学习日的规则, so that 深夜跨零点仍属于同一次学习日。
30. As a 学习者, I want a 换时区保留已有到期时间点的保证, so that 历史排程不会整体移动。
31. As a 学习者, I want a 时钟早于最近评分时阻止继续评分的保护, so that 错误时间不会污染学习历史。
32. As a 学习者, I want a 默认 20 张新卡首次评分和 50 次其他评分的独立每日额度, so that 我能控制学习负担。
33. As a 学习者, I want a 额度可设为零且当天调整保留已用次数的设置, so that 我能暂停某类出卡而不清空记录。
34. As a 学习者, I want a 到期且额度允许的分钟级学习优先、新旧卡按比例穿插的队列, so that 短期巩固和新词学习都能推进。
35. As a 学习者, I want a 尚未到期时显示等待时间并可结束本轮的行为, so that 应用不会要求提前学习。
36. As a 学习者, I want a 旧卡按到期学习日排序、同日打乱且新卡按加入先后出现的规则, so that 出卡顺序可理解。
37. As a 学习者, I want a 刷新与重启保持已有队列的能力, so that 重新打开不会重新洗牌或重置额度。
38. As a 学习者, I want a 评分后同词另一张新卡或长期卡暂缓到下一学习日的规则, so that 刚见过的答案不会立即提示另一张卡。
39. As a 学习者, I want a 已进入分钟级学习的同词卡仍按时出现的行为, so that 同词暂缓不会破坏短期步骤。
40. As a 学习者, I want a 单个或批量暂停、恢复同词两张卡的入口, so that 我能调整学习范围并保留历史。
41. As a 学习者, I want a 再次加入或音频修复不解除主动暂停的保证, so that 我的暂停选择持续有效。
42. As a 学习者, I want a 可跨重启撤销最近一次评分的操作, so that 误评分可恢复进度、到期时间、额度和队列变化。
43. As a 学习者, I want a 撤销不回退后续内容和设置编辑的保证, so that 修正评分不会丢失其他工作。
44. As a 学习者, I want a 下次复习时间排序, so that 我能先找到原始排程更早的生词。
45. As a 学习者, I want a 评分保存失败保留当前卡片且显示错误的行为, so that 我能安全重试而不重复扣额度。
46. As a 既有用户, I want a 升级保留 M1 生词、摘要、来源和笔记的保证, so that 新复习功能不会损坏原有数据。

## Implementation Decisions

- 延续 ADR 0001、0002、0004、0005、0006：资源与学习数据分离，同词一份生词记录，识义卡与听音卡独立进度；学习日与绝对时间分别表达。不得恢复已被替代的整条词典快照模型。
- 首选验证候选是固定 `fsrs-rs v6.6.2`（FSRS-6）及该版本官方默认模型参数。原生与 WASM 复用同一纯 Rust 核心；不提供参数优化，不加额外间隔随机扰动。候选不可用时报告原因并重新评估，不静默替换。
- 复用现有共享核心、存储、桌面平台适配和 RuntimeAdapter 边界。纯核心不访问文件系统、SQLite 或 Tauri；平台提供时间上下文与音频能力，存储负责事务，界面负责展示与交互。具体数据库字段和 IPC 形状留给实现，不把未验证候选写成已接入服务。
- 增量迁移保留全部 M1 用户内容；失败回滚，遇到更高 schema 报错而非重建。升级不自动为既有生词建卡。
- 同词同类型卡唯一。加入复习默认建立两种卡；音频失败仍保留卡片和进度，识义卡可用，听音卡标记“待生成语音”并排除可评分队列。再次加入补缺失 / 失败音频，不重建进度或解除暂停；重复收藏不影响卡片。
- 收藏自动加入默认关闭，只作用于开启后新收藏；关闭不暂停或删除已有卡片。单个与批量加入、暂停、恢复均在生词本提供；选择规则与逐词结果按用户故事执行。
- 背面采用收藏时的微型兜底摘要，不保证完整义项覆盖。默认只显示词头、简明释义与一组对应某个展示释义的法中例句；更多内容按需展开。例句与译文独立于笔记、两卡共用，沿用显式保存、离开保护和修订冲突检查；用户修改不被资源更新覆盖、不重置进度。
- 内置例句须核查许可、来源和质量；不依赖 AI 补齐。任一语言缺项均标“待补例句”，允许保存已有部分并继续复习。
- 听音正面不展示单词文字，进入自动播放一次，可重播，翻面不自动播放。已有音频播放失败须提示并允许重播 / 跳过；本次尚未成功播放不能评分。跳过不改排程、不扣额度；重新生成通过生词本加入复习重试。
- 新生成语音的默认存储格式确定为 Ogg Opus，目标码率 48 kbit/s；语音按常速生成，慢速通过 0.6 倍播放实现。实际编码、播放、兼容性和发行许可仍须在产品集成时验证，不改变已有数据。
- 目标保持率默认 90%，范围 70%–99%、步长 1%，两类卡共用。仅后续评分使用新值，不批量重排旧卡；输入、核心返回值和 IPC 在边界校验，拒绝无效数值与任意资源路径。
- 新卡初学为 1 分钟、10 分钟；长期遗忘进入 10 分钟重学。每次评分更新相应 FSRS 记忆状态；进入长期使用该次 FSRS 结果，不另造固定毕业间隔。步骤如下：

| 当前阶段 | 忘记 | 困难 | 记得 | 轻松 |
| --- | --- | --- | --- | --- |
| 首次出卡 / 初学第一步 | 1 分钟，回第一步 | 5 分 30 秒，保持第一步 | 10 分钟，进最后一步 | 进入长期 |
| 初学 10 分钟步骤 | 回 1 分钟第一步 | 保持 10 分钟步骤 | 进入长期 | 进入长期 |
| 长期复习 | 10 分钟重学 | FSRS 排程 | FSRS 排程 | FSRS 排程 |
| 重学 | 10 分钟，保持重学 | 15 分钟，保持重学 | 回到长期 | 回到长期 |

- 学习日按当前设备本地凌晨 4 点划分，经过天数按跨学习日计算，不能用固定秒数除法替代日历运算。分钟步骤从实际评分时刻计算完整间隔；长期天数四舍五入并限制为 1–36,500 天，在目标学习日凌晨 4 点到期。已有到期时间存实际时间点，换时区仅改显示。时钟早于最近评分时暂阻评分、提示检查时间，仍可查看生词，保留历史直到时间恢复。
- 每日新卡额度默认 20，按每张卡首次成功评分计；其余每次成功评分均消耗复习作答额度，默认 50，包含初学 / 重学重复。两项独立、均可设为 0；同词两类卡分别计数。当天改上限保留已用次数，剩余最低为 0；学习日切换重置额度，重启不重置。翻牌、重播、编辑、失败评分和同一操作重试不额外计数。
- 队列优先出已到期且额度允许的分钟级学习卡；按实际纳入队列的新旧卡数量比例均匀穿插。旧卡按到期学习日先后、同日打乱，新卡按加入先后；刷新和重启保持已有顺序。无可出卡时区分未到期与额度耗尽，提示等待或调整设置，不提前学习。
- 评分成功后，同词另一张未开始新卡或长期卡暂缓至下一学习日，保留原始到期时间与进度；分钟级学习不因此暂缓，仍受到期与额度约束。暂停按单词作用于两卡；恢复沿用原排程，继续遵守音频、额度及同词暂缓规则。
- 每次评分原子提交卡片前后状态、有效评分记录、核心版本 / 参数 / 保持率、实际时间与时间上下文、经过天数、额度影响、同词暂缓及队列变化；保留必要日志及完整状态快照，以支持重放与恢复。失败不推进界面；重复点击、丢响应、重启重试须幂等。
- 一级撤销跨重启保留，只恢复最近评分造成的状态与队列变化，返还该评分对原学习日额度的影响；不回退后续内容或设置，不以旧快照覆盖并发修改。撤销自身也须可安全重试。
- 生词本下次复习时间取同词已学习卡中最早的原始到期时间，较早优先；尚未学习的记录随后，未加入复习的最后；同时间按词头稳定排序。同词暂缓、暂停及每日额度不改写原始排程。
- 单词离线语音提前至 M2；引擎、权重、声线及完整文本前端仍须准入，不能靠模型标签推定许可。按 2026-10-26 用户决定，Windows / macOS 各 x86-64、ARM64 分别提供内嵌 TTS 模型的完整版和可通过“额外资源”下载模型的 Lite 版；完整版不受 200 MB 上限约束，Lite 保留既有体积目标，词典等其他资源不变。分别报告压缩下载量、安装占用及系统依赖；这些发行功能尚未实现。
- 生成音频仅作为 portable 数据目录内可再生成的临时文件，按[架构约束](architecture.md)定期清理；清理不能删除用户学习数据或改变卡片进度。缺失音频继续遵守“待生成语音”及已有重试规则，未接入前不宣称清理已运行。

## Testing Decisions

- 用户已确认以下边界：共享 Rust 核心的原生 / 实际 WASM 固定向量对照；存储公开接口的事务、幂等、队列及重启撤销；RuntimeAdapter 的界面行为；Windows x64 原生禁网语音生成与播放验收。优先从这些公开边界验证用户可见结果，不为私有函数堆叠重复测试。
- 核心覆盖四档评分及上表全部阶段、同日 / 跨日、保持率端点与非法输入、分钟完整间隔、长期取整上下界、凌晨 4 点、夏令时、换时区、时钟倒退与历史重放。必须实际加载并执行编译后的 WASM，现有版本 ABI 检查不构成调度证据。记忆数值容差须有实测依据；阶段、步骤秒数、整数间隔和到期日严格比较，不能以浮点容差放行整天偏差。
- 存储集成测试沿用现有公开 API 加真实 SQLite 的先例，覆盖 M1 升级保留、迁移回滚、高版本拒绝、两卡唯一、并发冲突、重复操作 / 丢响应重试、评分事务失败与无重复扣额、批量部分成功、暂停 / 恢复、设置及队列重启恢复，以及跨重启 / 跨学习日撤销且保留后续独立编辑。
- 队列在相同公开边界覆盖额度为 0、当天上下调额度、分钟重复计数、到期优先、比例穿插、同日打乱后重启顺序保留、同词暂缓与分钟步骤例外、等待而不提前出卡及下次复习时间排序。使用固定时间和可复现顺序，避免依赖测试机器当前日期。
- 界面沿用现有生词本 E2E 与原生调用 fixture，覆盖单个 / 批量选择、自动加入仅影响新收藏、卡面及评分可见条件、缺例句、编辑失败 / 冲突 / 离开保护、音频失败 / 重播 / 跳过、保存失败保留当前卡及三语错误 / 空状态。浏览器预览继续明确报告原生能力不可用，不模拟存储或语音成功。
- 原生验收用真实用户库与重启，覆盖断网加入、生成 / 播放、评分、队列与额度恢复、一级撤销、音频生成失败后重试且保留进度，以及 portable 数据路径。真实听音质量用法语短词、重音、撇号、连字及未知词等样本记录结果；浏览器 fixture 不替代此验收。
- FSRS 与语音验证先行，记录固定版本、来源、校验和、许可义务、全部前端 / 运行依赖、覆盖与质量、压缩体积及通过 / 失败 / 未测证据。参考上游设计与测试，不复制不兼容许可实现，尤其不将 Anki AGPL 实现复制到项目 MIT 源码。
- 实现时运行 README 要求的 lint、typecheck、build、适用 E2E、Rust 格式 / 编译 / 相关测试、实际 WASM 构建执行。存储测试先 `pnpm rust:test:build` 后 `pnpm test:rust`，保持执行阶段硬 60 秒超时。维护验证记录并分别列出通过、失败和未运行；测试后停止本次启动的进程。

## Out of Scope

- 语法卡、反向卡、拼写输入或自动判分、分类、导入导出、同步、Google OAuth、翻译及 AI 服务。
- FSRS 参数优化、自定义模型参数、额外间隔随机扰动、多级撤销、批量重排已有到期时间。
- 完整变位、例句朗读和完整离线核心；本次仅提前单词离线发音与播放。
- 第二阶段浏览器复习产品与 BFF；实际 WASM 运行仅为共享调度核心验收，不等于交付 Web 学习应用。
- M5 四目标正式发行、签名 / 公证及完整默认资源准入；不把首条 Windows x64 运行链路等同全部平台通过。

## Further Notes

- 规格依据仓库 M2 确认稿 Q1–Q42、产品基线、开发路线、资源准入要求及 ADR 0001 / 0002 / 0004 / 0005 / 0006 合成；测试边界在本次对话中已确认。具体语音 / 例句资源、数据库字段和 IPC 仍由准入及实现落实，不宣称已有验证结果。
- 当前 M1 正式规格为 [#10](https://github.com/zardonc/lexique/issues/10)。Windows x64 M1 已有运行证据；macOS 专属编译、退出保护与恢复仍 blocked，Windows ARM64 只有编译证据。M2 首条运行验收采用 Windows x64 原生与实际 WASM，其他目标继续编译检查，实际运行另列待验证，不降低既有 macOS 阻塞和 M5 四目标门槛。
- 语音许可、完整文本前端、法语质量、真实禁网生成 / 播放和完整压缩体积尚缺证据。FSRS / WASM 与语音可行性未通过前，不推进为已经验证的完整集成，也不能将 M2 标为全部完成。
- 规格发布不代表业务实现已开始或运行验收通过；ready-for-agent 表示规则已明确，技术准入验证是本规格的首项工作。
