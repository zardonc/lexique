# 生词本词频颜色标记

日期：2026-11-08。状态：用户要求已纳入；统计来源与产品分档标准已选定，资源转换和界面尚未实现。正式跟踪见[后续计划](lookup-notes-speech-plan.md)与[总规格 #1](https://github.com/zardonc/lexique/issues/1)。

## 来源与统计口径

实施票为 [#57](https://github.com/zardonc/lexique/issues/57)，标 `ready-for-agent`；转换及随包资源的准入是该票的验收工作。

采用原作者发布的 **Lexique 3.83**，固定版本以便重现；它不是当前最新 Lexique 4。主指标为 `freqlemfilms2`：电影／电视剧字幕语料中的词元频率，单位为每百万词出现次数。`freqlemlivres` 可作为小说语料参考，不能混入主指标。来源、原始列名、语料及许可证据见[一手来源核查](evidence/french-word-frequency/README.md)和[原作者版本说明](https://chrplr.github.io/openlexicon/datasets-info/Lexique383/README-Lexique.html)。

字幕语料适合本产品的常用词参考，但不代表所有现实口语、现代专门领域或教学分级。词频不推导 CEFR；A1–B2 词表仍按自己的来源与许可门槛准入。

同一标准词头的一份生词记录包含多个词性／义项。本产品对对应词元的各词性分别取一份 `freqlemfilms2`，再合计为词头频率；这是本产品的汇总标准。

- 查询资源时可使用 NFC 和小写的资源搜索键，保留重音及来源拼写；这不改变生词记录身份、只读词头或原始查询。其他异写关系须有可靠依据。
- 原始数据按 `(NFC(lemme), cgram)` 去重；屈折形式行重复携带词元频率，不能逐行相加，也不能仅筛 `islem=1` 后丢弃没有原形行的词元。
- 同组有效数值必须一致；缺失、非法数值、组内冲突或尚无可靠原形关联时显示“暂无词频”，可查看原因及候选，不任取首项、最大值或零值。
- 已有可靠词元且源值明确为零时归入低频；资源缺失与未收录保持未知。屈折词形只有可靠关联后才使用对应词元的统计。
- 例如原表 `a priori` 的 ADV 为 1.04、NOM 为 0.41；词头合计 1.45 次／百万词，按下述标准为低频。

## 颜色及用户可见信息

以下是 **Lexique 产品分档标准**，不是语料作者公布的等级边界：

| 条件：每百万词出现次数 F | 标签 | 颜色角色 |
| --- | --- | --- |
| F ≥ 100 | 高频 | 绿色 |
| 10 ≤ F < 100 | 中频 | 蓝色 |
| 0 ≤ F < 10 | 低频 | 橙色 |
| 没有可靠数值 | 暂无词频 | 灰色 |

词汇记录在生词本列表和详情的标准词头旁显示标记；标签与颜色同时出现。详情可查看数值、统计口径、Lexique 3.83 来源和词性合计。纯白、暖色与深色主题均须可读，辅助技术可读到标签，颜色不作为唯一提示。

词频标记由只读资源派生；资源替换后可以重新计算，资源不可用时仍显示已保存记录、摘要及笔记。此显示不自动修改分类、收藏、FSRS 进度或单词音频；词频着色与动词变位词尾着色分别使用各自规则。
