# 法语语音偏好

2026-10-26 用户确认设置中提供“法语女声／男声”和“正常／慢速”，并授权为满足许可及质量要求更换声音或模型。最初选择 Piper；MLS 随后因人工试听失败撤回，目前试验 Supertonic 3，尚未认定正式声线。

- MLS medium 已因用户试听确认读音混乱、音质不佳撤回，不作为产品声线。失败组合为：女声源编号 `3698`（推理编号 `1`），男声源编号 `1840`（推理编号 `0`）；默认女声、正常语速。许可依据与边界见[替代准入记录](evidence/issue-14/replacement-admission.md)。
- 偏好独立于学习进度，保存到现有用户库的 `app_metadata`，不增加 schema 版本。声线使用稳定的 `female`／`male`；旧 `siwis`／`tom` 分别兼容为女声／男声，保存时使用新值，不丢失原语速。
- 设置分别保存声线与语速；保存失败保留待保存选择并显示错误，不显示保存成功。
- 浏览器预览不冒充桌面持久化，禁用保存并说明限制。
- 当前只保存偏好，应用的离线合成、播放、音频缓存尚未接入；不增加无效试听按钮。
- 当前替代探针为 Supertonic 3 int8：女声 F1（`sid=0`）、男声 M1（`sid=5`），八步去噪。用户确认初次英语和法语样本可用，且[试听对照](evidence/issue-14/supertonic-slower/listen.html)的 `0.6` 倍播放清晰自然。统一以 `speed=1.0` 合成，播放时常速使用 `1.0`、慢速使用 `0.6`，共享同一音频；产品合成和播放尚未接入。
- 用户确认单独字母 `y` 使用字母名 /iɡʁɛk/，试听候选由 `i grec` 合成。代词 `y` 的 /i/ 是不同用法，不能将字母名自动套用到代词；产品尚未实现语境选择。
- 模型许可、默认包体与跨平台门槛继续按现有资源准入流程核查；选择候选引擎不代表这些已通过。

当前四组合样本见[Supertonic 试听页](evidence/issue-14/supertonic-samples/listen.html)，许可条件及来源见[替代调查](evidence/issue-14/replacement-options-after-mls.md)。模型与格式比较见 [#14 对比报告](evidence/issue-14/comparison.md)。

2026-10-26 用户确认：Windows / macOS 的 x64 / ARM64 各提供完整版和 Lite 版。完整版内嵌 TTS 模型，不受 200 MB 包体上限限制；Lite 不内嵌模型，用户可在“额外资源”主动下载后离线使用。其他内置资源不变。此项为发行需求，应用的模型下载、合成、播放及四架构发行仍待实现和验收。
