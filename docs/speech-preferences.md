# 法语语音偏好与 WPM

更新：2026-11-08。[#56](https://github.com/zardonc/lexique/issues/56)已接入共用朗读语速。Windows x64 的真实 SQLite、原生重启、播放及学习数据保持检查通过；端点清晰度与音高的人工试听待确认。命令、校准和限制见 [#56 证据](evidence/issue-56/README.md)。

## 设置与播放

| 项目 | 行为 |
| --- | --- |
| 单位 | WPM，每分钟朗读的书写词数；界面提供中文、英语、法语解释 |
| 范围与档位 | 80–240 WPM，步长 20；键盘与滑动使用相同档位 |
| 默认 | 法语女声、180 WPM |
| 预设 | 慢速 100、正常 180、快速 240 WPM |
| 试听 | 短句使用待保存的声线与 WPM |

单词预览、听音卡与逐表达变位共用已保存设置及 `speechPlaybackRate` 换算。当前播放保持原速，下一次播放读取新保存的 WPM。例句朗读入口仍属后续离线模块，接入时复用同一规则。

继续使用 Supertonic 3 int8 F1（`sid=0`）／M1（`sid=5`）、CPU、正常合成 `speed=1.0`、八步去噪及 48 kbit/s Ogg Opus。WPM 只改变播放速率；播放器明确开启音高保持，不重新合成或替换选定音频。

三条法语句子分别含 15、17、21 个书写词；按含字母／数字的空白分隔项计数，撇号／连字符内部不拆分，纯标点不计，句内停顿计入完整时长。总词数除以总时长得到女声基准 **149.256686 WPM**、男声基准 **149.148901 WPM**；播放速率为目标 WPM 除以对应基准。单词与短表达沿用句子基准，不按短文件倒算精确 WPM。

音频响应携带录制声线。听音卡使用选定版本的声线，即使全局声线已改变；未知旧声线使用女声基准并显示近似提示。端点播放器与原始校准音频见[试听页](evidence/issue-56/listen.html)。

## 保存与既有数据

偏好仍独立保存在用户库 `app_metadata`，没有 schema 迁移。成功保存写入 `{"voice":"female","wpm":180}` 形式的 JSON；声线限定为 `female`／`male`，WPM 必须为范围内的整数档位。

旧 `normal` 读取为 180、`slow` 读取为 100 WPM；旧 `siwis`／`tom` 仍分别读取为女声／男声。读取不改写旧记录，成功保存才写新格式。该映射保留原选择意图，不表示与历史播放倍率完全等价。

只有无偏好时使用默认值。非法范围、非整数、不在 20 WPM 档位、未知字段及损坏内容保持错误。保存失败保留待保存选择、旧持久设置及真实错误；浏览器预览明确禁用桌面持久保存和试听。

既有生词、摘要、笔记、卡片身份、独立进度、评分历史、当前作答、选定音频版本和保护关系保持。缺失资源、合成及播放失败继续显示真实错误。
