# 法语语音偏好

2026-10-26 用户确认：采用 Piper，设置中提供“法语女声／男声”和“正常／慢速”。

- 女声候选为 SIWIS medium，男声候选为 Tom medium；默认女声、正常语速。
- 偏好独立于学习进度，保存到现有用户库的 `app_metadata`，不增加 schema 版本。
- 设置分别保存声线与语速；保存失败保留待保存选择并显示错误，不显示保存成功。
- 浏览器预览不冒充桌面持久化，禁用保存并说明限制。
- 当前只保存偏好，应用的离线合成、播放、音频缓存尚未接入；不增加无效试听按钮。
- 后续合成需使用选定的模型和速度；慢速倍率仍需试听校准，不能只靠播放降速替代合成验收。
- 模型许可、默认包体与跨平台门槛继续按现有资源准入流程核查；选择 Piper 不代表这些已通过。
