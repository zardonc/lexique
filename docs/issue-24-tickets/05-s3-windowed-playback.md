## What to build

用户进入大型词库复习时，数据库只提供候选与摘要，近期窗口经过严格完整文件校验，播放器解码／播放同一份字节。坏未展示卡有界修复／补位，全坏返回明确进度，不扫完全库才响应；已经展示的题面／答案／翻面和合法内存播放保持，本次播放未成功不能评分。

## Acceptance criteria

- [ ] 本票改前执行Q08、A01、A03、C04相关红检查及V01／V04／V05；使用稳定版本元数据直接检查，不再次逐词查询旧key／asset。

- [ ] 起点B50／W4／K8／2验证worker／32MiB压缩预算／75ms等待／最多100缺失词样例可配置实测；固定线程、后继工作／payload有界，超预算真实处理中，不能以OS读不可取消不断开线程。
- [ ] 安全句柄／nofollow／路径／重解析、完整有界读、Ogg／长度／SHA与不可变version绑定；校验buffer就是播放器实际字节，normal／0.6复用，压缩／PCM／Blob／IPC内存分别记录。
- [ ] 未展示坏候选条件标记、持久去重修复／补位；metadata全缺失probe为零，metadata-ready全坏strict≤K并继续可观察异步收敛，不能伪报已确定全库坏计数。

- [ ] 音频生成／清理／修复竞争、外部替换／截断／坏hash／超限／链接／权限／codec能力不足分类可见；真实损坏才修复，能力不足不污染全部设备状态或循环生成。
- [ ] T24-Q08、Q09、A01–A05、A07、A08、P03与原T03／T08／T09相关真实FS／UI／原生播放通过；健康／已知缺失oracle一致，全坏最终收敛，fixture头不算实播。
