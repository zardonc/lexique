# B02／S1：批量读取复习快照并保持资格、额度和持久顺序

## Parent

[#24 复习队列、选定单词音频与安全清理规格](https://github.com/zardonc/lexique/issues/24)。

## What to build

让当前桌面复习从真实数据库批量读取资格、设置、额度、进度及当天位置，消除逐卡／逐词／逐资产重复查询和不必要写事务，并修复双额度零时日内听音卡漏出。结果经现有平台／RuntimeAdapter到复习页，与既有权威规则及独立参考结果一致。

此阶段复用旧音频模型与完整安全检查，不提前消费尚未建立的选定版本或窗口协议；单纯批量查询仍可能遍历／解析候选，不能宣称全库O(1)或已达到最终播放窗口目标。

## Acceptance criteria

- [ ] 先复现本票相关V01／V03及Q01／Q04／Q10红回归，复用S0数据与预算，保留原支持行为基线。
- [ ] 从一致短快照批量读取卡片／progress／设置／已用额度／位置及现有音频元数据，复用连接和位置map；真实IPC阶段计数证实不再逐卡／词／资产N+1。
- [ ] 无progress或空due的新卡纳入；跨日学习优先、日内重复不限额度，双额度零仍出到期日内听音；新20／复习50及忽略开关、成功评分计数／撤销返还不变。
- [ ] 长期准入沿现有到期学习日／FNV／身份，实际过滤后比例混排；暂停／会话跳过／当天锚点保留，不能先任意limit再混排或把当天entries当全库。
- [ ] 日切／缺位／重编号用必要短事务，稳定热刷新无位置重写或legacy登记；文件／合成／解码不持读写事务，条件修订冲突有限重读且失败可见。
- [ ] 评分／撤销事务再次校验进度及资格、原operation重试幂等；另一连接改额度／暂停／进度后旧队列不能放行非法评分，重编号UNIQUE／溢出／提交失败及重启不改变相对顺序。
- [ ] T24-Q01–Q07、Q10、C02、C04、C05及原T02／T03相关规则与真实SQLite／原生IPC回读通过；所有类别健康／已知缺失输出与独立oracle一致。
- [ ] 交付同输入前后SQL／事务／文件／IPC及首卡时间对照；前端若改动完成lint／typecheck／build／适用UI，Rust按locked编译、相关回归及预编译后的60秒执行，记录结果／剩余瓶颈。
