## What to build

旧库安全升级后，现有生词仍能用原来实际可读的音频发音，并明确拥有一个选定当前内容版本。偏好修改不隐式换掉已有声音，删卡不解除生词音频归属。读取、初次生成／绑定与旧清理恢复同步接入不可变版本和统一保护协议，用户看到真实迁移／不可用状态。

本票交付兼容升级、首次选定及基本安全发布／绑定的完整链路；后续票扩展最新更换／修复与全面故障恢复，不允许本票在中间状态留下第二套GC删除权威。

## Acceptance criteria

- [ ] 先完成本票V04／V05的真实DB／FS验证；增量结构保留生词、双卡身份、笔记、历史、暂停和完整JSON；失败回滚不提高schema，较高schema拒绝降级重建。
- [ ] 内容版本有独立且不可复用的发布实例身份／locator／hash，规格键与非确定输出分开；每词最多一个选定当前、独立修订／目标generation与上一版关系；任务、校验和GC状态分别建模。
- [ ] 首次选定前安全完整读取旧流程实际可用的首选内容；legacy复制同一份校验字节形成兼容不可变实例，提交前保留原文件；未知声线／模型／生成时间仍unknown。
- [ ] 分块登记可中断／重复恢复，近期优先；未初始化旧owner临时保护，unknown文件保留，marked内容先恢复且不能直接绑定；迁移显示处理中而不阻塞其他识义学习。
- [ ] 现有读取／初次生成／收藏及原生播放使用明确选定版本；提交前不报告可用，新文件／引用失败保留旧内容；改变偏好只影响以后生成，正常／0.6播放不创造第二版本。
- [ ] 任一当前生词绑定永久保护共享版本，删卡／暂停／归档不detach；旧规格GC、pending-GC及兼容读取转交版本级同一仲裁，迟到旧删除不能触及新current；不以等待S6为由保留误删窗口。
- [ ] 热队列读取不反复登记legacy或找最多20个旧变体；可用legacy不自动替换，坏旧文件不停止主管／其他请求；T24-G01、L01、L02、L05及关联G04／G05保护烟测通过。
- [ ] 真实旧库升级、原生播放与重启回读字节／选择／数据不变；平台IPC校验及UI迁移／失败状态可验证，记录本票README要求检查、60秒执行和未测平台。
