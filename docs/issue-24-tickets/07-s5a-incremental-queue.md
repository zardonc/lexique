# B07／S5a：增量更新队列并保证自动触发和当前作答稳定

## Parent

[#24 复习队列、选定单词音频与安全清理规格](https://github.com/zardonc/lexique/issues/24)。

## What to build

连续评分后有限更新当前卡、额度、分钟到期和预读窗口，减少重新读取全库；所有既有自动触发从进入／返回、业务提交、音频到时间边界可靠到达。通知风暴保持一个在途、合并与最终可见，空闲／隐藏不持续查库。后台更新始终保护当前题面／翻面／合法已播放版本。

无需等待S4的可选投影或特定连接池；在既有权威数据／S3窗口上实现，差分失败可明确回退DB-only并报告增量未验收。

## Acceptance criteria

- [ ] 先执行本票V01／V05与C01红回归；缓存delta带前后queue revision，提交成功才生效，操作／请求代次不混用，no-op不无故增revision。
- [ ] 连续正常评分有限更新／refill，记录返回行数、解析量、重建次数及原因；每次一条固定全表SQL仍重扫不能算增量，不能无声回退却宣称完成。
- [ ] 日切／时区／设置、暂停／卡集合、跳过、时钟异常／休眠、撤销或修订不匹配有明确失效／重建；音频事件只影响相关词／窗口；真实资格仍评分事务核验。
- [ ] 原全部自动触发在空／非空队列覆盖：进入重入／焦点可见性／后台休眠、评分撤销跳过暂停、提交建卡／启用收藏自动加入、相关发布重试清理、额度及下一到期／04:00；正常无刷新按钮、故障定向重试。
- [ ] 一查询在途、有界合并与最大等待、查询末尾变化尾随重算、逆序响应不覆盖／复活旧卡；普通音频事件100–250ms为初值，持续流最终收敛不无限推迟。
- [ ] 稳定空闲新增队列I/O零，隐藏无轮询，恢复重核验；卸载释放订阅／定时器／播放等待，应用任务继续，当前题面／答案／翻面及合法已播放buffer不被更新替换。
- [ ] T24-C01、P02及原T01–T03／稳定性八类相关UI／DB／原生差分通过，随机操作oracle最终顺序／计数／唤醒一致。
- [ ] 分报评分成功返回后已预读UI切卡p95≤20ms目标与点击到持久提交／播放端到端、单次／累计触发成本及事件风暴；失败／未达和回退可见，适用检查及60秒执行保持。
