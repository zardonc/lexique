# B09／S6a：落实音频保护期、软容量及安全清理恢复

## Parent

[#24 复习队列、选定单词音频与安全清理规格](https://github.com/zardonc/lexique/issues/24)。

## What to build

把选定内容的保留、访问有效性、后台清理与容量反馈接成真实桌面闭环：当前生词音频永久，上一版14天、最后归属解除7天、临时生成完成起7天；200MiB软目标优先清理无保护内容。多归属／发布／使用／清理竞争不误删，失败及占用可诊断并恢复，音频缺失不影响学习身份或进度。

不新增删词／恢复上一版UI；其事务边界可用公开存储测试验证，未来产品入口必须沿同协议。当前与上一版基本保护已在S2建立，本票不能成为较早票放任旧GC误删的理由。

## Acceptance criteria

- [ ] 本票V04／V05与G04改前回归有可重复依据；UTC Unix秒、604800／1209600秒及安全溢出校验；生成完成／成功选择提交／最后归属解除分别起算，等于边界即到期，重复事件不续期。
- [ ] 任一当前绑定永久保护，删卡／暂停／归档不detach；每词上一版最多一份14天，再替换只释放该词更早上一版保护，多引用及孤儿保护取最晚有效期限。
- [ ] 临时到期访问拒用，不依赖物理维护；读取／播放／下载／恢复不改expires_at，有效临时收藏事务化复用，过期／marked不复活；无卡生词、同时生成／GC收藏及共享last owner竞争正确。
- [ ] 无当前归属逻辑占用软目标209715200字节，永久／保护期／可回收／tmp与实际分配分列；先到期／多余再无保护临时LRU，仍超标只报告，容量不提前破坏当前或有效保护期。
- [ ] 每批≤100条件mark具体version／mark generation、事务外安全delete、条件finish；未过保护／有intent／占用不删，迟到旧GC与同hash重发布不误删新实例，失败／缺文件／重复恢复各有真实结果。
- [ ] 启动先关键intent恢复，再低优先分块对账（200项、6小时为初值）；枚举指纹是线索，使用SHA验证同大小／mtime替换，unknown保留，portable移动不误报业务损坏，维护可暂停恢复。
- [ ] 期限／容量／归属／权限／磁盘／重解析及读中／发布中竞争通过T24-G02–G07及原T08／T09／T12；不删除模型／词典／用户库，失败保留日志和下次重试，不改变卡片／进度。
- [ ] 真实文件／SQLite／原生重启及容量状态反馈有证据；诊断不泄漏学习内容，相关README检查、60秒分片及owned进程清理保持。
