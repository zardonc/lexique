# D2 ça / NOM 词义与准入调查

调查：2026-11-17（UTC）；范围批准：2026-11-16（America/Vancouver）。基线：`7de4b213298c219bf812562faea79c6621631025`。关联：[content 001，#81](https://github.com/zardonc/lexique/issues/81)。

## 结论与已批准决定

核查的五个词典来源均将日常指示用法归入代词，将明确的 `ça` 名词义限定为精神分析的**本我**。本轮没有在这些来源查到满足原 #81 要求的现代日常名词义。Lexique 3.83 的 `ça / NOM` 是真实源记录，不能按拼写错误删除，也不能借用相邻 `ça / PRO:dem` 的释义完成它。[法兰西学院第九版](https://www.dictionnaire-academie.fr/article/A9C0002)、[TLFi 的 CELA, ÇA](https://www.cnrtl.fr/definition/%C3%A7a/pronom)、[Larousse 名词条](https://www.larousse.fr/dictionnaires/college/%C3%A7a/5848)、[Le Robert](https://dictionnaire.lerobert.com/definition/ca)、[维基词典固定修订 39860132](https://fr.wiktionary.org/w/index.php?title=%C3%A7a&oldid=39860132#Nom_commun)。

2026-11-16（America/Vancouver），用户明确批准**仅对冻结第 34 行 `ça / NOM` 采用有据的专业义例外**。该行保留；第 35 行的日常指示代词独立保留；全部冻结成员、4,087 分母及其他来源、质量、四字段和实际执行门槛继续适用。此决定允许验收这个有明确领域的名词，日常义覆盖仍单独计数。[#81 冻结成员与验收](https://github.com/zardonc/lexique/issues/81)。

支持的名词身份为 `ça`，IPA `/sa/`，**阳性、仅单数、不可数、精神分析**。含义是人的心理中承载无意识驱力的部分；英语译词为 `id`。上述词性、限制、读音与英语译词均来自固定修订的名词段落；中文说明应解释同一精神分析概念。[39860132 · Nom commun](https://fr.wiktionary.org/w/index.php?title=%C3%A7a&oldid=39860132#Nom_commun)。
