# 生词笔记的 CSV 与模板式 Markdown 导入导出规格

2026-11-19。产品行为、测试边界与工单拆分已确认，规格发布为 [#183](https://github.com/zardonc/lexique/issues/183)。

## Problem Statement

用户需要把 Lexique 的词汇笔记拿到表格或 Markdown 工具阅读、整理，再将编辑后的内容导回，也需要导入外部已有的词汇笔记。完整学习数据备份携带应用状态，不能替代仅交换笔记内容的通用文件。现有生词保存依赖词典信息，限制了词典未收录笔记的导入。

## Solution

提供 UTF-8 CSV 和约定模板的 Markdown 双向交换，仅传递词头、独立笔记及全部法语／中文笔记例句。支持全部生词、当前搜索结果和单条导出。导入先预览字段映射、错误与同词差异，用户选择有效记录后一次保存；外部笔记可以暂缺词典信息，保存后可编辑并主动加入双卡复习。

## User Stories

1. 作为词汇学习者，我希望导出全部生词笔记，以便在外部工具集中整理。
2. 作为词汇学习者，我希望导出当前搜索结果，以便只交换选定主题或词组。
3. 作为词汇学习者，我希望导出一条已保存的记录，以便单独阅读和修改。
4. 作为表格工具使用者，我希望用 CSV 导入和导出，以便使用 Excel、Google Sheets 或 LibreOffice。
5. 作为表格工具使用者，我希望一条例句占一行，以便直接编辑每组法语与中文内容。
6. 作为表格工具使用者，我希望选择逗号或分号分隔符，以便读取已有表格文件。
7. 作为表格工具使用者，我希望把外部列名映射到交换字段，以便复用已有词汇表。
8. 作为 Markdown 工具使用者，我希望每词一个文件，以便在 Obsidian 等工具独立整理。
9. 作为 Markdown 工具使用者，我希望正文能读到所有字段，以便直接检查词头、笔记和例句。
10. 作为 Markdown 工具使用者，我希望纯文本内容原样往返，以便保留空白、多行和反引号。
11. 作为 Markdown 工具使用者，我希望批量导入和导出 ZIP，以便一次交换多份模板笔记。
12. 作为词汇学习者，我希望中文、法语重音和引号保持原样，以便导回后内容不变。
13. 作为词汇学习者，我希望所有例句保持顺序，以便保留原来的学习安排。
14. 作为词汇学习者，我希望没有例句的笔记也能交换，以便保存只含词头或正文的记录。
15. 作为词汇学习者，我希望单侧例句可以保存，以便稍后补充译文或法语原句。
16. 作为词汇学习者，我希望完全相同的内容自动跳过，以便重复导入不产生重复记录。
17. 作为词汇学习者，我希望同词内容有差异时先看预览并选择更新或跳过，以便控制覆盖行为。
18. 作为词汇学习者，我希望未提供的笔记字段保留旧内容，以便只更新文件中实际编辑的字段。
19. 作为词汇学习者，我希望明确空值清空对应字段，以便通过外部工具删除内容。
20. 作为词汇学习者，我希望例句整组替换，以便新原句不会与旧译文错配。
21. 作为词汇学习者，我希望原样未变的例句保留义项关联，以便导回不丢失已有整理。
22. 作为词汇学习者，我希望新增或改变的例句可暂不关联义项，以便先保存再补充。
23. 作为词汇学习者，我希望词典未收录的词也能导入，以便保存自己的外部笔记。
24. 作为词汇学习者，我希望看到真实导入来源和缺失信息，以便了解记录是否已关联词典。
25. 作为词汇学习者，我希望新词精确匹配已安装词典时补充词典信息，以便继续使用查词与复习内容。
26. 作为词汇学习者，我希望词典读取错误区别于未收录，以便决定是否继续保存未关联笔记。
27. 作为词汇学习者，我希望导入更新保留已有词典信息和分类，以便内容交换不改变其他整理。
28. 作为词汇学习者，我希望预览显示无效记录的位置与原因，以便修正文件或排除记录。
29. 作为词汇学习者，我希望同词文件内容冲突时整组标错，以便避免自动拼接不一致的笔记。
30. 作为词汇学习者，我希望排除错误记录后仍能导入有效内容，以便局部错误不阻止其余笔记保存。
31. 作为词汇学习者，我希望选定记录整批成功或整批失败，以便不会留下半批更新。
32. 作为词汇学习者，我希望预览后发生编辑时重新确认，以便导入不覆盖更新的内容。
33. 作为词汇学习者，我希望导入不自动加入复习或生成音频，以便先整理内容再决定复习范围。
34. 作为词汇学习者，我希望主动为外部笔记加入识义卡和听音卡，以便复习不受词典覆盖限制。
35. 作为词汇学习者，我希望重复加入或导入不重置进度和暂停状态，以便继续已有学习安排。
36. 作为词汇学习者，我希望听音卡仍要求可用且已播放的音频才能评分，以便保持已有听音规则。
37. 作为词汇学习者，我希望重启后能继续编辑导入的笔记与未关联例句，以便外部内容成为正常学习数据。
38. 作为词汇学习者，我希望完整备份／恢复保留外部记录，以便内容交换扩展不会损害已有恢复能力。
39. 作为词汇学习者，我希望取消选择、预览或保存时得到明确结果，以便知道是否已写入数据。
40. 作为词汇学习者，我希望文件写入失败和非法 ZIP 内容有真实错误，以便不会误以为导出或导入成功。

## Implementation Decisions

- 沿用生词记录、独立笔记、笔记例句与笔记内容交换的领域模型。第一版只交换词汇记录；语法与分类已有功能继续保留。
- 交换文件仅含词头、笔记和法语／中文例句。词典引用、微型兜底摘要、义项关联、例句来源、分类、卡片、进度、历史与音频不写入交换文件。
- CSV 规范列为 headword、notes、example_fr、example_zh；导出用带 BOM 的 UTF-8 和逗号分隔，导入接受 UTF-8 有无 BOM及显式选择逗号／分号。用成熟 CSV 能力处理引用与多行，不自行按换行或分隔符拆分文本。
- CSV 必须有词头列；每个目标字段最多映射一列，未映射的外部列忽略。规范列自动识别，外部列可手动映射。文件结构无法解析或必需映射缺失时先修正，不进入提交。
- 一条例句一行，同词重复词头和同一份笔记；同词可在非连续行出现，按首次出现建立记录顺序，组内例句保持文件行序。没有例句保留一行空例句。空例句不生成额外学习内容；不对非空例句自动去重。
- Markdown 必须有固定标识 Lexique note v1 和 headword 章节；notes、examples 可省略。例句采用编号及 fr、zh 子章节，编号唯一且连续，从 1 开始。提供空章节表示清空；遗漏章节表示未提供。未知结构、重复字段、非法编号和无法闭合的文本块在预览中报错。
- Markdown 所有字段放在正文的 text 围栏内，按纯文本读取。导出围栏长于正文中的任何连续反引号序列；结构分隔换行与字段自身换行明确区分，保留字段原字符串。
- 单词 Markdown 独立保存，批量用 ZIP。文件名用 Windows 可用的可读词头加已保存记录编号；身份从正文取得。直接读取 ZIP 中模板条目，不按其中路径解压；非模板条目报告文件级错误，用户排除后可继续有效记录。损坏或不可读取的容器先修正。
- 导出范围、计数、排序与字段来自同一份已保存数据快照；当前搜索结果包括该查询的全部匹配词汇记录。编辑器未保存草稿不参加导出。沿用当前生词本排序，空范围禁用导出并说明没有记录。
- 词头身份只做现有 NFC 等价归一，保留大小写、重音与撇号区别，不依据文件名、外部编号或宽松搜索自动合并词头。
- 导入允许生词暂缺词典逻辑引用和微型兜底摘要，以独立导入来源标识保存。不得用虚构词典、地址或释义填充缺失值。扩展既有记录模型及请求／响应校验，并适配列表、详情、编辑、双卡、音频归属与完整学习快照的读取和保存。
- 新词精确匹配已安装的本地词典时，复用现有词典选择与校验规则补充引用和摘要，含已支持的自定义词典。匹配不改变交换词头身份；不扩展为词形猜测、模糊匹配或远程查询。
- 词典未收录、资源缺失、损坏和读取失败分别展示。发生资源错误时须由用户明确选择继续保存未关联内容；无该选择则不提交受影响记录。已有记录更新保持其原词典信息，包括已保存的丰富摘要。
- 文件实际提供的笔记字段替换原笔记，明确空值清空，缺失则保留。新记录缺失内容为空。提供任一例句列或 examples 章节时，替换整个有序例句列表；缺少的语言侧为空，完全没有例句字段则保留原列表。
- 保留原样未变例句的义项关联和来源；新增或文本改变的例句不继承旧关联及旧词典署名。内容相同且重复的例句按原有出现顺序对应，不通过猜测关联义项。
- 先按实际提供字段计算有效更新，再判断相同／有差异。相同内容跳过；不同内容必须手动选择更新或跳过，不自动拼接。CSV 同词组笔记不一致、Markdown 同词文件提供字段或内容不一致时整组冲突；完全相同的 Markdown 同词文件只处理一次。
- 沿用现有内容限制：词头非空且最多 200 个 Unicode 字符、无控制字符；笔记和每个语言侧最多 20,000 个 Unicode 字符；主例句加额外例句最多 101 组。超限不截断，预览显示行／文件、词头与原因。
- 桌面文件选择、读取和写入走已有平台边界，前端通过现有 RuntimeAdapter 提供映射、预览、选择与结果。复用现有 storage 校验、SQLite 事务和操作重试机制；格式转换共用导入内容语义，避免 CSV 与 Markdown 各有保存规则。
- 提交时重新校验所选记录与预览修订，包括新词在预览后被创建。出现冲突则整批停止并重新预览。所选有效记录同一事务提交，失败全部回滚；响应丢失后的重试不得重复创建或重置已有进度。
- 导入只保存内容，不沿用全局自动加入设置，不投递语音任务。成功后可明确选择单个或批量加入双卡；既有卡片进度、历史、主动暂停、选定音频与其他未交换数据保留，新记录使用现有空／默认分类。
- 未关联词典的外部记录可继续编辑并手动加入双卡。卡背显示笔记、例句与缺失信息；听音评分沿用可用音频与播放门槛。继续使用现有音频生命周期，不因导入引入新的音频协议。
- 完整学习数据备份／恢复必须容纳新记录形态及真实导入来源，继续接受已支持的旧备份。按现有快照版本规则处理必要的格式演进，不新增一套兼容或迁移框架。

## Testing Decisions

主要测试边界是桌面笔记内容交换应用入口：真实临时文件进入解析与预览，经所选提交写入真实 SQLite，再经重新打开、导出或完整备份／恢复核对结果。优先复用现有词汇存储、保存修订／幂等操作、学习快照校验和桌面备份文件测试的边界；只替代无法自动操作的文件选择，不模拟文件系统和数据库。

浏览器 E2E 验证映射、差异、排除、取消与结果呈现。实际 Windows 原生检查复用 WebView2／CDP 启动真实可执行程序的方案，覆盖 Tauri 注册、真实文件与重启链路。模拟 IPC 的浏览器 fixture 只作为 UI 证据。以外部行为和持久结果断言，不测试私有辅助函数或重复验证既有 FSRS 算法。
