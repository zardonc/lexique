# 笔记保存内容快照，词典变更不覆盖正文

此记录保留历史决定，已被 [ADR 0004](0004-one-vocabulary-record-with-reference-digest-and-notes.md) 替代。2026-10-25 用户改为同词一份生词记录，采用逻辑引用、微型兜底摘要与独立笔记；不再采用下述整条内容快照与同词多笔记模型。词典与用户内容互不覆盖的边界继续有效。

2026-10-25 用户确认：从选中的一个词条创建词汇笔记，默认带入其全部释义，允许保存前删改；笔记保存当时的内容快照，并保留来源、许可和资源版本。词典更新或移除后，笔记正文仍保留。

相较于每次打开时从当前词典重新取得正文，这一选择让用户整理过的学习内容独立于词典资源变化，延续 [ADR 0001](0001-separate-bundled-resources-from-learning-data.md) 的边界。

同日用户进一步确认：不另存未经编辑的词典原文副本；查词展示词典原文，笔记展示用户编辑后保存的词头与正文，两者互不干扰。笔记身份独立于词头，允许同词多条笔记；编辑不改变身份。M1 不保存草稿。来源引用的具体保存字段与后续待决问题见[确认记录](../m1-note-saving.md)。
