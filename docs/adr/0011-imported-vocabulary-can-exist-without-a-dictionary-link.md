# 导入生词记录可独立于词典保存

2026-11-19。用户确认笔记内容交换允许导入内置词典未收录的词，交换字段为词头、独立笔记和例句。外部导入的生词记录可以暂缺词典逻辑引用和微型兜底摘要，以真实导入来源和缺失信息标识保存；新导入或内容已改变的例句可以暂不关联义项。

这一决定扩展 [ADR 0004](0004-one-vocabulary-record-with-reference-digest-and-notes.md) 的三层记录模型，使外部笔记的保存独立于词典覆盖；同一标准词头仍归属一份生词记录。导入更新仅作用于文件提供的内容，保留已有记录身份、词典信息与复习进度。

实施与验收由[笔记内容交换规格 #183](https://github.com/zardonc/lexique/issues/183)及其子 issue 跟踪。
