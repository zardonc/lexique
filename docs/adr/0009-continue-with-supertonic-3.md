# 后续开发继续使用 Supertonic 3

2026-11-08 用户确认继续使用已接入的 Supertonic 3 法语 CPU 语音，停止替代 TTS 模型测试。Kokoro [#6](https://github.com/zardonc/lexique/issues/6) 已测试且音质不满足要求，Pocket TTS [#7](https://github.com/zardonc/lexique/issues/7) 按未测试、取消计划处理；历史对照证据保留，后续开发不再以候选比较为前置条件。现有女声／男声、正常合成与 0.6 倍慢速播放及 [音频版本规则](0008-selected-word-audio-content-versions.md)继续适用，Supertonic 3 的[许可义务](0002-source-and-resource-licensing.md)、其他平台实机、干净机器和正式发行门槛仍按[准入清单](../development-readiness.md)验收。

同日新增需求将播放偏好改为 [80–240 WPM 目标朗读速度](../speech-preferences.md)，步长 20、默认 180；它替代本决定中正常／0.6 倍作为后续设置的表述，尚待实现。Supertonic 3、CPU、声线、正常合成及音频版本规则仍按本决定保持，历史倍率试听证据保留。
