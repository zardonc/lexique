# 同词保留一份生词记录，分离引用、摘要与独立笔记

2026-10-25 用户改为：同一个单词在生词本只保留一份记录，采用“逻辑引用 + 微型兜底摘要 + 独立笔记”，并相应调整查词模块。逻辑引用关联词典内容；微型摘要用于词典不可用时兜底；用户学习内容独立保存，不随词典原文更新而覆盖。

这一方向替代 [ADR 0003](0003-note-content-survives-dictionary-changes.md) 中默认复制完整词条内容、允许同词多笔记的模型，以减少冗余并保留资源缺失时的基本可读内容；继续遵循 [ADR 0001](0001-separate-bundled-resources-from-learning-data.md) 的资源与学习数据分离原则。

同日用户确认：同一标准词头只保留一份记录，不同词性和义项归入同一记录；重音区别保留，去重音只用于搜索。屈折形式仅在可靠识别原形后归并。独立笔记可以为空并随时编辑，修改仍遵循明确保存的规则。

M1 先用已有 FreeDict 小样验证三层记录、简要信息置顶、词典原文与独立笔记分开展示、收藏状态联动和重启恢复；其余查词增强待资源测试后补足，见[后续需求暂存](../deferred-lookup-requirements.md)。复习日期排序称为“下次复习时间”，较早到期优先，M2 有真实 FSRS 数据后启用。

用户进一步确认：标准词头只读；重复收藏只提示已存在并提供查看入口，不新增或覆盖。M1 摘要取当前 FreeDict 已有音标、语法及每个同头词条的一条中文译义，缺失明确标注，收藏时保存为只读兜底，词典更新不自动替换。

Q28 补充确认：M1 保留源词头的大小写和撇号区别，只归一同一文字的 Unicode 等价编码；更宽松的搜索不改变生词身份，更多异写归并待资源验证后另行确认。

用户提供的设计附件只作参考。全部已确认规则见[确认记录](../m1-note-saving.md)。本决定不采纳附件中的全部 SQL、去重键、同步或服务方案，也不表示这些能力已经实现。
