# 同一生词的识义卡与听音卡分别保留进度

2026-10-25 M2 访谈 Q3 确认：同一生词记录最多对应一张识义卡和一张听音卡，两张卡共用生词内容，但分别评分、分别排程。此关系延续 [ADR 0004](0004-one-vocabulary-record-with-reference-digest-and-notes.md) 的同词一份生词记录，不为两种考查复制生词内容。

识义熟练不等于能听音识词，因此不采用同词两种考查共享一份复习进度的方案。虽然需保留两份进度，但可避免一次识义评分错误地推迟听音复习；完整产品规则见[M2 确认稿](../m2-review-core.md)，具体存储结构留给实现。

Q7、Q10 补充：卡片通过生词本的单个 / 批量“加入复习”，或默认关闭的收藏自动加入选项创建；重复收藏不影响卡片，再次加入可重试生成音频并保留进度。因此卡片进度独立于收藏动作和音频生成结果，不用重建卡片的方式重试音频。
