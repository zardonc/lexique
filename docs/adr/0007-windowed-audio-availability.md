# 用数据库候选与近期校验窗口保障听音复习

2026-11-03 #24 访谈 Q3 确认：数据库就绪状态用于筛选候选，近期使用窗口仍严格安全读取并校验音频，播放器使用同一份字节，当前作答在后台修复期间保留。这样避免每次刷新读取全库文件；代价是窗口外音频状态可能过时，因此候选摘要与已验证可展示窗口分开，全部候选失效时采用有界校验和明确等待状态，而不承诺立即得到完整严格结果。完整事务、失效和测试边界见[优化方案](../issue-24-optimization-plan.md)与[测试计划](../issue-24-test-plan.md)。Q10 已共同确认设计基线；2026-11-04 工作区已接四卡窗口、固定校验 worker、真实修订及 delta，逐项运行与性能状态见[继续实现记录](../evidence/issue-24/continuation-2026-11-04.md)。
