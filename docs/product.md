# 产品基线

更新：2026-10-24。来源：原需求整合版、产品设计说明与最新原型修订。以下区别已确认需求、暂定选型和骨架实现；本文件不将历史演示当作技术验证。

## 已确认方向

- 面向 A1–C1 法语学习，默认词库目标 A1 / A2 / B1 / B2，界面支持中文、英语、法语。
- 使用应用无需账户；Google 连接和需凭据服务单独授权。AI 初版只接 OpenAI 兼容接口，用户自备凭据。
- 第一阶段 Windows 11 与 macOS，各支持 x64 / ARM64；最低 macOS 尚未正式确认。
- Windows 交付采用免安装 portable：解压后直接运行 `.exe`，运行数据、WebView 缓存、临时文件、配置和日志全部放在 `.exe` 同级的 `Lexique-data/`；移动时携带整个目录，不自动迁移或删除既有 AppData 数据。
- 默认词典和完整约定变位仍须随分发包提供。桌面发行分完整版和 Lite 版：完整版内嵌法语 TTS 模型，Lite 版不内嵌模型，由用户在应用的“额外资源”中主动下载后使用离线 TTS；未经下载时须明确提示语音不可用。
- 生词与语法笔记支持分类、导入导出、FSRS；SQLite 与允许人工编辑的 Google Sheets 双向同步。
- 浏览器自部署为第二阶段，必须实际使用 WASM，至少可复习闪卡；需要明确 BFF / OAuth / 访问控制方案。

## 功能范围

| 模块 | 目标 | 当前骨架 |
| --- | --- | --- |
| 词典 | 离线查询、联想、最近记录、释义、例句、发音、自定义 MDX/MDD | 固定 FreeDict 法中小样的原生只读查询、释义与来源；其余待接入 |
| 变位 | 任意已收录词形反查，完整表、全部匹配高亮、可重排 | 导航入口与未接入状态 |
| 生词本 | 词汇与语法、分类、导入导出 | M1 词汇三层记录、明确保存与编辑、搜索排序及原生重启恢复；语法、分类、导入导出待接入 |
| 闪卡 | FSRS 与跨端一致的进度快照 | 导航入口；没有伪造调度算法 |
| 主题 | 分级、主题、自定义或 AI 生成词汇 | 导航入口与未接入状态 |

## 暂定工程选择

Tauri 2 / TypeScript / Rust / SQLite 为已接受的暂定方案 A。这里选择 React / Vite 延续现有原型开发工具，但不将其描述为用户已经单独批准的最终前端框架。工作名为 Lexique；首个开发壳暂用原型 A 的左侧导航，不表示最终布局已经定稿。

纸面视觉沿用原型的纯白 `#f7f7f4`、暖色 `#f8f2e6` 和深色。纯白侧栏加深为 `#e7e7e2`；可收起为图标；复习入口仅在主导航，不在查词页内重复；“服务与密钥”去除 Baidu。这些是最新明确的原型修订。

## 必须保持的边界

同步冲突由用户选择本地或 Sheet。冲突触发规则、逐卡或整本裁决、删行 / 改 ID / 文本冲突和恢复语义尚未确认，骨架没有选择任何自动合并策略。

离线词典、变位、分级词表和模型的来源、质量与再分发许可尚待核实。没有发布 Reverso 网页、第三方词典、模型或原型的演示记录。来源网页可供评估，不能证明有再分发权。

默认在线翻译服务、业务数据库字段、FSRS 参数 / 版本、分类结构、OAuth 回调 / BFF 拓扑及最低 macOS 尚待决定。具体候选资源和分阶段准入门槛见 [开发准备清单](development-readiness.md)。

2026-10-26 语音选择：设置提供法语女声／男声（MLS medium 因音质失败撤回，Supertonic 3 候选样本随后获用户试听认可）及正常／慢速；默认女声、正常。当前已接偏好的桌面保存与恢复，合成、播放及缓存仍未接入。完整引擎分发材料与包体仍须验收；其他三平台验证不阻塞 #14，但仍属于后续桌面发行要求，详见[语音偏好](speech-preferences.md)。

2026-10-24 补充确认：项目自有源码采用 MIT；第三方资源分别核查其许可。默认包只接受允许按目标方式转换、再分发且没有非商业用途限制的资源，可以接受署名及数据的相同方式共享条件。内置词典和变位可以转换为只读结构化资源，优先评估 SQLite；自定义 MDX/MDD 支持继续保留，资源库与用户学习数据分别管理。

2026-10-26 发行方式调整：Windows / macOS 各提供 x64 和 ARM64，每种组合均提供完整版及 Lite 版，共八种发行物。完整版不受 200 MB 安装包上限限制，但应减少重复资源和磁盘占用；Lite 保留既有包体目标，另列模型下载及安装占用。两版的词典、变位和其他内置资源不因本次调整改变。包体、安装占用和系统运行依赖分别计量；Windows 11 主便携包优先使用已有 WebView2，缺少时提供官方独立离线依赖包与检测提示。该发行方案及 Lite 下载尚未实现。

2026-10-27 用户确认新生成语音默认采用 Ogg Opus 48 kbit/s；24 kbit/s 对照样本存在同一句内音量忽大忽小的听感，48 kbit/s 未出现该问题。默认格式是待实现的产品要求，不表示应用已接入编码、存储或播放。

2026-10-27 补充：生成的语音是可再生成的临时文件，须保存在 portable 应用目录内并定期清理；清理不得删除模型、词典或用户学习数据，也不得重置卡片进度。实现和验证仍待后续语音接入。
