# 产品基线

更新：2026-10-24。来源：原需求整合版、产品设计说明与最新原型修订。以下区别已确认需求、暂定选型和骨架实现；本文件不将历史演示当作技术验证。

## 已确认方向

- 面向 A1–C1 法语学习，默认词库目标 A1 / A2 / B1 / B2，界面支持中文、英语、法语。
- 使用应用无需账户；Google 连接和需凭据服务单独授权。AI 初版只接 OpenAI 兼容接口，用户自备凭据。
- 第一阶段 Windows 11 与 macOS，各支持 x64 / ARM64；最低 macOS 尚未正式确认。
- 默认词典、完整约定变位、法语离线语音模型最终需要随安装包提供，不能用首次下载替代首装离线要求。
- 生词与语法笔记支持分类、导入导出、FSRS；SQLite 与允许人工编辑的 Google Sheets 双向同步。
- 浏览器自部署为第二阶段，必须实际使用 WASM，至少可复习闪卡；需要明确 BFF / OAuth / 访问控制方案。

## 功能范围

| 模块 | 目标 | 当前骨架 |
| --- | --- | --- |
| 词典 | 离线查询、联想、最近记录、释义、例句、发音、自定义 MDX/MDD | 导航入口与未接入状态 |
| 变位 | 任意已收录词形反查，完整表、全部匹配高亮、可重排 | 导航入口与未接入状态 |

| 主题 | 分级、主题、自定义或 AI 生成词汇 | 导航入口与未接入状态 |
| 翻译 | 中英法互译，普通服务与 OpenAI 兼容 AI 分开接入 | 导航入口，无网络调用 |

## 暂定工程选择

Tauri 2 / TypeScript / Rust / SQLite 为已接受的暂定方案 A。这里选择 React / Vite 延续现有原型开发工具，但不将其描述为用户已经单独批准的最终前端框架。工作名为 Lexique；首个开发壳暂用原型 A 的左侧导航，不表示最终布局已经定稿。

纸面视觉沿用原型的纯白 `#f7f7f4`、暖色 `#f8f2e6` 和深色。纯白侧栏加深为 `#e7e7e2`；可收起为图标；复习入口仅在主导航，不在查词页内重复；“服务与密钥”去除 Baidu。这些是最新明确的原型修订。

## 必须保持的边界

同步冲突由用户选择本地或 Sheet。冲突触发规则、逐卡或整本裁决、删行 / 改 ID / 文本冲突和恢复语义尚未确认，骨架没有选择任何自动合并策略。

离线词典、变位、分级词表和模型的来源、质量与再分发许可尚待核实。没有发布 Reverso 网页、第三方词典、模型或原型的演示记录。来源网页可供评估，不能证明有再分发权。

TTS 引擎、默认在线翻译服务、业务数据库字段、FSRS 参数 / 版本、分类结构、OAuth 回调 / BFF 拓扑及最低 macOS 尚待决定。具体候选资源和分阶段准入门槛见 [开发准备清单](development-readiness.md)。

2026-10-24 补充确认：项目自有源码采用 MIT；第三方资源分别核查其许可。默认包只接受允许按目标方式转换、再分发且没有非商业用途限制的资源，可以接受署名及数据的相同方式共享条件。内置词典和变位可以转换为只读结构化资源，优先评估 SQLite；自定义 MDX/MDD 支持继续保留，资源库与用户学习数据分别管理。

包体按每个系统 / 架构完成首装离线功能所需的压缩下载总量衡量，目标小于 100 MB、预期上限 200 MB，功能正确优先；默认词典、变位、模型及必要推理资源均计入。安装占用和系统运行依赖另外列明，超出预期上限时先报告明细并由用户决定，不能改为首次启动下载默认核心资源。Windows 11 主安装包优先使用已有 WebView2，缺少时提供官方独立离线依赖包与检测提示；同时报告主包、依赖包及缺依赖机器的完整离线下载总量。
