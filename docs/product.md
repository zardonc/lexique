# 产品基线

更新：2026-11-11。来源：原需求整合版、产品设计说明与用户确认。以下区别已确认需求、工程选择和实际实现；本文件不将历史演示当作技术验证。

## 已确认方向

- 面向 A1–C1 法语学习，默认词库目标 A1 / A2 / B1 / B2，界面支持中文、英语、法语。
- 使用应用无需账户；云存储连接和需凭据服务单独授权。AI 初版只接 OpenAI 兼容接口，用户自备凭据。
- 第一阶段 Windows 11 与 macOS，各支持 x64 / ARM64；最低 macOS 尚未正式确认。
- Windows 交付采用免安装 portable：解压后直接运行 `.exe`，运行数据、WebView 缓存、临时文件、配置和日志全部放在 `.exe` 同级的 `Lexique-data/`；移动时携带整个目录，不自动迁移或删除既有 AppData 数据。
- 默认词典和完整约定变位仍须随分发包提供。桌面发行分完整版和 Lite 版，两版均使用 Supertonic 3：完整版内嵌模型，Lite 版不内嵌模型，由用户在应用的“额外资源”中主动下载后使用离线 TTS；未经下载时须明确提示语音不可用。
- MDX 词典仅选择 1–2 份法语相关资源随完整版和 Lite 分发；其余候选仅内置来源／下载页链接，供用户自行选择。当前 Windows x64 开发包已接入一份 FreeDict 法英 0.4.1 补充 MDX，原内容为 2018-08-11；设置提供八类、12 项自选链接，见[接入证据](evidence/d2-mdx/README.md)及[候选与格式核实](d2-resource-admission-research.md#法语随包范围与用户自选链接)。MDD 配套、完整默认词典／分级及完整版／Lite 正式发行仍分别验收；变位、词频、OCR 和 TTS 继续按各自范围交付。
- 生词与语法笔记支持分类、导入导出、FSRS；学习数据在应用内查看与修改，跨云文件同步面向 Google Drive、OneDrive 等存储，按阶段分别验收。
- 浏览器自部署为第二阶段，必须实际使用 WASM，至少可复习闪卡；需要明确 BFF / OAuth / 访问控制方案。

## 功能范围

2026-11-08，共用朗读语速为 80–240 WPM、步长 20，默认女声／180；提供 100／180／240 预设与短句试听。单词、听音卡及逐表达变位共用保存偏好，当前播放保持原速，下一次播放使用新 WPM；例句朗读后续复用同一规则。Windows x64 原生持久化与播放检查通过，人工端点试听通过，见[语音偏好](speech-preferences.md)。

2026-11-07，M3 变位已完成约定的 Windows x64 验收：23 个语式／时态区块、七个独立重点标记、英文译义／传统组别／助动词、普通主动式与代词式、三种着色模式、完整表达反查和逐形式发音。用户已报告 #49 的新鲜完整语音包断网验收通过；匹配格式 6 的 reader、资源、学习数据保持及逐项证据见 [#38 收尾](evidence/issue-38/README.md)。[变位范围](m3-conjugation-scope.md)保持不变；其他 M3 模块和 M5 正式发行按各自门槛推进。

## 新增需求与首期范围（2026-11-08）

用户确认首期就支持其他应用选中文本查词和屏幕区域框选 OCR，同时保留应用内选词、图片导入／粘贴截图。识别结果可编辑、核对后选词，复用真实离线词典；默认本地 CPU OCR，系统权限、支持应用、快捷键与多屏分别验收，详见[翻译输入](translation-inputs.md)。这些离线输入属于 M3，在线翻译／AI 服务仍按 M4 接入。

生词本列表及详情的词头新增“高频／中频／低频／暂无词频”颜色与文字标记。来源选定 Lexique 3.83 字幕词元频率，按词性去重合计，每百万词 100／10 为产品分档边界；缺失或不可靠关联保持未知，词频不替代 CEFR。数据许可为 CC BY-SA 4.0，转换及随包材料仍须验收，详见[词频标准](word-frequency-colors.md)。

播放速度以 WPM 表示朗读语速，单词、例句与变位共用；最低 80、最高 240、步长 20、默认 180，并提供试听。优先直观易用与清晰播放，按声线基准近似换算，旧 normal／slow 分别读取为 180／100。继续使用 Supertonic 3，速度变化不重建音频或学习进度，详见[语音偏好](speech-preferences.md)。

词频只读资源及法语 OCR 运行库／数据按默认资源准入后随完整版和 Lite 提供，首次断网可用；Lite 仍只省去内嵌 TTS 模型。包体与通知在相应资源及 M5 逐项验收。

共用 WPM、词频标记、系统选词与屏幕 OCR 已完成 Windows x64 检查，见 [#56](evidence/issue-56/README.md)、[#57](evidence/issue-57/README.md)、[#58](evidence/issue-58/README.md)和 [#59](evidence/issue-59/README.md)。多 MDX 标签／按需正文与已有动词的显式原形选择已通过 [#9 D1／D3 验收](evidence/issue-9/README.md)。既有干净系统报告保留，其他平台测试按用户要求暂缓。后续为完整默认词典／分级与剩余离线核心 → M4 → M5 → M6，详见[纵向交付计划](lookup-notes-speech-plan.md)。

## 暂定工程选择

Tauri 2 / TypeScript / Rust / SQLite 为已接受的暂定方案 A。这里选择 React / Vite 延续现有原型开发工具，但不将其描述为用户已经单独批准的最终前端框架。工作名为 Lexique；首个开发壳暂用原型 A 的左侧导航，不表示最终布局已经定稿。

纸面视觉沿用原型的纯白 `#f7f7f4`、暖色 `#f8f2e6` 和深色。纯白侧栏加深为 `#e7e7e2`；可收起为图标；复习入口仅在主导航，不在查词页内重复；“服务与密钥”去除 Baidu。这些是最新明确的原型修订。

## 必须保持的边界

多设备应用各自持有本地副本，不能把“应用是单一数据源”解释为当前客户端覆盖其他设备。同步设计建议保留记录 / 卡片分歧并在应用内裁决，云文件被直接修改走校验、隔离及显式导入 / 修复；冲突、删除、来源认证与恢复的具体协议仍是 M4 前置门槛，见[同步设计](sync-design.md)。

完整默认词典和分级词表仍需核实来源、质量与再分发许可；当前变位资源和 Windows x64 Supertonic 3 包的准入与分发材料见 #38 收尾。来源网页可供评估，不能证明有再分发权；其他平台、干净机器与正式发行义务继续逐项验收。

默认在线翻译服务、业务数据库字段、FSRS 参数 / 版本、分类结构、OAuth 回调 / BFF 拓扑及最低 macOS 尚待决定。具体候选资源和分阶段准入门槛见 [开发准备清单](development-readiness.md)。

2026-11-08 语音选择：继续使用已接入的 Supertonic 3，不再测试其他 TTS 模型。Kokoro #6 已测试但音质不满足要求；Pocket TTS #7 未测试、取消计划。现有 CPU 执行、法语女声／男声、正常合成及音频版本规则保持；共用播放偏好已改为 WPM，详见[语音偏好](speech-preferences.md)和 [ADR 0009](adr/0009-continue-with-supertonic-3.md)。许可、其他平台实机与 M5 正式发行仍按各自门槛验收。

2026-10-24 补充确认：项目自有源码采用 MIT；第三方资源分别核查其许可。默认包只接受允许按目标方式转换、再分发且没有非商业用途限制的资源，可以接受署名及数据的相同方式共享条件。内置词典和变位可以转换为只读结构化资源，优先评估 SQLite；自定义 MDX/MDD 支持继续保留，资源库与用户学习数据分别管理。

2026-10-26 发行方式调整：Windows / macOS 各提供 x64 和 ARM64，每种组合均提供完整版及 Lite 版，共八种发行物。完整版不受 200 MB 安装包上限限制，但应减少重复资源和磁盘占用；Lite 保留既有包体目标，另列模型下载及安装占用。两版的词典、变位和其他内置资源不因本次调整改变。包体、安装占用和系统运行依赖分别计量；Windows 11 主便携包优先使用已有 WebView2，缺少时提供官方独立离线依赖包与检测提示。该发行方案及 Lite 下载尚未实现。

2026-10-27 用户确认新生成语音默认采用 Ogg Opus 48 kbit/s；24 kbit/s 对照样本存在同一句内音量忽大忽小的听感，48 kbit/s 未出现该问题。Windows x64 的编码、存储与播放已在 [#15](evidence/issue-15/README.md)接入，其他平台按各自门槛验收。

语音文件保存在 portable 应用目录内，清理不得删除模型、词典或用户学习数据，也不得重置卡片进度。选定内容永久保留、旧版和临时内容限期保留的现行规则由下述 #24 与 ADR 0008 确定，并已接入 Windows x64。

2026-10-29 #15 交付：单个生词加入双卡、卡面、失败重试与 Windows x64 原生重启恢复已接入。语音开发包使用 Supertonic 3 及 48 kbit/s Ogg Opus，慢速对同一音频使用 0.6 倍速；机器合成标识、缓存、安全清理和持久错误日志已实现，实播与缓存回归通过，见 [#15 证据](evidence/issue-15/README.md)。后续评分、队列及音频保留已分别完成 #22／#24 的 Windows 验收；其他目标及正式完整版 / Lite 发行仍待后续。

2026-11-02 用户确认：生成语音只使用 CPU，不使用 GPU；例句音频缓存七天；仍在生词本中的单词，其单词音频持久保留，临时查询七天删除。2026-11-03 Q1–Q10 已细化为每词一个选定当前内容永久、上一版自成功切换十四天、最后归属解除七天、临时自生成完成七天，读取不续期；200 MiB 软容量优先保护这些关系。此规则覆盖早期“所有语音均为临时缓存”和访问续期，见 [ADR 0008](adr/0008-selected-word-audio-content-versions.md)及 [#24 规格](issue-24-spec.md)。当前 schema 17 已接 CPU 主管、共享内容归属、绝对期限、统一 GC／容量／分块对账、有界四卡窗口及增量更新；窗口和本日实际需求可自动修复，远期保留已提交批量需求。已有识义／听音独立进度和当前作答继续保留，综合验收及性能按[继续实现记录](evidence/issue-24/continuation-2026-11-04.md)逐项完成。批量与未来网页研究见 [补充研究](evidence/issue-24/concurrency-batch-web-research.md)，不代表网页／例句引擎已接入。

2026-11-02 同步方向更新：应用统一负责查看、编辑和裁决；后台限频批量同步，已确认操作在下一次上传前也须本地持久保存。此要求替代允许人工编辑 Sheets 及在表格 / SQLite 两端维护数据的旧目标。推荐桌面 SQLite + 事务 outbox，JSON 清单 + 不可变 JSONL 交换；M6 由 IndexedDB 宿主提交业务状态及 outbox，WASM 继续执行共享调度。CSV / XLSX / PDF 可作按需查看导出，不参与自动回写。方案、默认间隔、设备退役与 GC 仍需进入门槛验证，尚未实现；见[格式评估](sync-format-evaluation.md)、[同步设计](sync-design.md)和[总规格 #1](https://github.com/zardonc/lexique/issues/1)。
