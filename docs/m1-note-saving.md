# M1 笔记保存规则确认记录

日期：2026-10-25。状态：Q1–Q29 已逐项确认，正式实施规格已按[任务跟踪规则](agents/issue-tracker.md)发布为 [#10](https://github.com/zardonc/lexique/issues/10)。Windows x64 的 M1 链路及 release portable 已验证；macOS 仍为 **blocked — 等待 macOS 执行环境**。本文保留访谈规则与历史检查记录，当前平台边界见下文。

## 已确认规则

以下按最新用户答复维护；Q17 的新方向替代早先“整条内容快照、同词多笔记”的决定。附件仅为设计参考，不自动成为全部已确认需求。

1. M1 完成离线查词 → 创建词汇笔记 → SQLite 保存 → 生词本查看、编辑 → 关闭应用并重启后恢复。语法笔记、分类管理、卡片生成和导入导出留给后续范围；它们仍属于产品目标。
2. 生词本改为“逻辑引用 + 微型兜底摘要 + 独立笔记”，不再默认把所选词条的全部释义复制为笔记正文。Q20 已确认 M1 用已有 FreeDict 小样完成简要信息置顶、词典原文与独立笔记分开展示、同词收藏状态联动、三层保存与重启恢复；资源缺失字段明确显示缺失。其他查词增强在资源测试后补足，已单列[暂存需求](deferred-lookup-requirements.md)。
3. 词典原文与用户独立笔记互不覆盖；词典更新或移除不删除用户内容。三层方向见 [ADR 0004](adr/0004-one-vocabulary-record-with-reference-digest-and-notes.md)，它替代 [ADR 0003](adr/0003-note-content-survives-dictionary-changes.md) 的整条内容快照模型；领域用语见[词汇表](../GLOSSARY.md)。
4. 使用明确的“保存”按钮，仅在本地数据库写入成功后显示“已保存”。失败时保留编辑内容并允许重试；离开未保存的编辑页时提醒。
5. 用户学习内容继续采用支持换行的纯文本，允许添加例句和个人理解；来源与许可信息独立展示。Q22、Q24 已确认独立笔记允许为空、可随时编辑或清空，上限 20,000 字符；修改仍需明确保存。标准词头为只读锚点，要收藏另一个词须重新查词加入。此项替代早先“词头可编辑、学习正文必填”的要求。
6. 同词一份记录替代 Q6 的同词多笔记。Q19 已确认按标准词头归属，同词的不同词性和义项归入同一记录；保留重音区别，`cote`、`côte`、`côté` 不自动合并，去重音只服务搜索。Q28 已确认 M1 保留源词头的大小写和撇号区别，只归一同一文字的 Unicode 等价编码；更多异写归并待资源验证后确认。变位形式仅在可靠识别原形后归并，M1 不推断尚无资源支持的变位映射。同一次保存的重复点击或失败重试不能产生副本。
7. 不另存完整的词典原文副本。Q25 已确认 M1 摘要取自当前 FreeDict 已有内容：音标、语法信息，以及每个同头词条的一条中文译义；缺失字段明确标注，不补造。收藏时保存这份只读摘要，词典更新不自动覆盖；资源不可用时用它保留基本信息。完整摘要资源与刷新策略留在后续需求中。
8. M1 不加入删除；删除、撤销删除与恢复规则在后续单独确认。
9. 不保存草稿，不提供跨重启的草稿恢复；仅保存成功的笔记保证重启恢复。运行期间保存失败保留编辑输入，正常离开或退出时提醒；崩溃、强制结束或断电后不保证保留未保存内容。运行期间的编辑输入不是另一条已保存笔记。
10. 词头为非空单行、最多 200 个字符，作为只读锚点；独立笔记支持换行，最多 20,000 个字符，允许为空或清空。保留重音、大小写与笔记排版，超限提示而不截断。不将旧版“正文只含空白视为空”解释为新独立笔记必须非空，也不为摘要引入 100 字节硬上限。
11. 来源信息自动记录、只读，不随用户笔记修改而改写历史来源。逻辑引用用于查询可用词典的相应词头，历史来源与收藏时的兜底摘要独立保留，不以资源升级覆盖用户内容。
12. 离开未保存内容时提供“保存后离开”“放弃修改”“继续编辑”。保存失败停留并保留输入；放弃修改时，已有笔记恢复到上次保存的内容，新笔记取消创建。正常退出应用也遵循此规则。
13. 生词本列表展示词头与内容摘要，点击查看详情和独立笔记；保存成功留在当前记录并显示“已保存”。M1 包含搜索与自定义排序，暂不增加筛选。Q29 已确认按词头字母顺序、创建时间或修改时间排序，各支持正序 / 倒序，记住上次选择并在重启后恢复，默认最近修改优先。Q21 已确认新增排序项称“下次复习时间”，较早到期优先，M2 接入真实 FSRS 后启用，M1 不生成模拟日期。未学习记录的位置留待 M2 确认。
14. Q23 已确认重复收藏提示“已在生词本”并提供“查看现有记录”，不新建，也不覆盖已有摘要、独立笔记或复习状态。Q27 已确认并发编辑冲突时展示现有内容，提供“采用现有内容”和“返回编辑”：前者明确提醒将放弃本次未保存修改，后者保留输入、不写数据库。返回编辑不解除后续保存的冲突检查；不提供强制覆盖或自动合并，采用现有版本后可以重新编辑。
15. Q26 已确认搜索范围为标准词头、兜底摘要、独立笔记。继续忽略大小写与重音，按连续文字片段匹配；清空显示全部，结果沿用当前排序；不做模糊纠错或词形推导。搜索的去重音规则不是身份合并规则。
16. Q18 已确认：保存异常提示错误与重试，不生成副本。若数据库已写入但响应丢失，重试仍需遵循无副本规则；不得提前显示成功或用新身份绕过失败。

- 摘要内容优先于附件的约 100 字节目标，不将该数字当硬性约束；不能截断 UTF-8 或编造缺失的 IPA、CEFR、原形及释义。M1 来源与缺项政策已在 Q25 确认，完整摘要的后续规则仍待资源验证。

- 复习日期是排程结果；FSRS 另有稳定度和可提取性等记忆状态，见 [FSRS 官方说明](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)。产品名称已在 Q21 确认为“下次复习时间”。

## 实现时应验证的场景

以下保留访谈形成的验收场景；逐项结果与平台限制以[验证记录](verification.md#m1-生词记录与独立笔记issue-10)及 [Windows 后续证据](evidence/issue-10/windows-follow-up.md)为准，不能仅凭场景列表认定通过：

- 真实原生窗口在禁网环境从 FreeDict 查询同头多词条，创建一份生词记录；笔记为空也能保存，默认摘要保留每个同头词条的一条中文译义，缺音标 / 语法明确显示缺失。
- 同词的多词性 / 多义项共用记录；重音、大小写或撇号不同的源词头不被宽松搜索误合并，同一文字的 Unicode 等价编码不产生重复记录。重复收藏、连续点击保存和结果不明后的重试均不新增副本、不覆盖已有内容。
- 编辑 / 清空独立笔记，保存成功后关闭并重启真实应用；词头、摘要、来源、笔记及身份回读一致。只读词典原文没有被用户编辑改写。
- 词典缺失、损坏或升级后，生词记录与独立笔记仍可读取，并可使用收藏时摘要；查词仍明确报告资源问题，不把兜底内容冒充原文。
- 搜索覆盖标准词头、摘要和独立笔记，验证大小写 / 重音、字面片段及清空行为；验证词头、创建时间、修改时间的正序 / 倒序、默认最近修改优先，以及重启后恢复上次排序偏好。
- 空笔记可保存，20,000 字符边界与超限提示符合规则；超限不截断，不改变已保存内容。
- 写入失败、响应丢失与数据库不可用时不提前显示成功，输入保留，重试不产生副本。事务失败保留既有数据，不将读取失败显示为生词本为空。
- 两个编辑者修改同一记录，旧版本保存被拒绝；采用现有内容前明确提醒放弃未保存修改，返回编辑保留输入且不解除冲突检查。
- 离页 / 正常退出的保存、放弃、继续编辑分别符合规则；保存失败停留。未保存输入不承诺跨崩溃恢复，不引入草稿持久化。

验证沿用已有界面 / RuntimeAdapter、真实 SQLite、原生重启等边界；按仓库要求运行检查、先预编译存储测试并保留 60 秒执行上限。浏览器模拟响应不替代原生持久化证明。

Windows x64 已验证 FreeDict 小样查词、同词一份三层记录、显式保存、幂等重试、版本冲突、搜索排序与原生禁网重启恢复；用户库已增量迁移至 schema 2。收藏时的来源与兜底摘要独立保存，资源词条编号不直接用作生词身份。debug 与 release portable 的运行证据见[验证记录](verification.md#m1-生词记录与独立笔记issue-10)及 [Windows 后续证据](evidence/issue-10/windows-follow-up.md)。

macOS 专属编译、原生退出与数据恢复仍为 **blocked — 等待 macOS 执行环境**；已知 Dock Quit 可能绕过未保存保护，须按[阻塞清单](macos-m1-blockers.md)修复并实测。Windows ARM64 仅编译通过，尚无实机运行证据。分类、卡片、FSRS、同步、TTS、完整资源与正式发行不在当前通过范围。

本次状态更新只对齐已有实现及证据，不改变产品规则、数据库或 IPC，也不增加运行验收结论。
