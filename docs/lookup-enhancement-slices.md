# 查词增强的有界切片草案

2026-11-09，依据[暂存票 #9](https://github.com/zardonc/lexique/issues/9)。用户已确认按本页继续 D1 多 MDX 标签与按需加载、D3 已有动词范围的可靠原形关联；D2 的完整词典／CEFR 来源继续保留准入门槛。#56–#59 已完成 Windows x64 检查。下述产品行为为已确认范围，缓存及性能预算在实施前依据实测固定。D4 的真实 FSRS 排序继续沿用 #21／#22；C1–C4 不随本草案整体采纳。

## D1：多 MDX 的首次产品接入

建议按用户的词典顺序显示标签，初次仅加载首个可用词典的正文，其余标签点击后加载。切换词典保留查询；单个词典缺失、损坏、不支持或无结果分别显示，其他词典仍可查询。每个结果保持自己的来源与文件版本，不合并物理 ordinal 或静默覆盖已保存摘要。

复用[已验收的 mdictlib 0.2.8 + LZO 支持矩阵](evidence/issue-3/README.md)，先限定已实测的 v1／v2、UTF-8／UTF-16 与压缩组合。原始 HTML／CSS／脚本不得获得 main 窗口原生权限；正文显示隔离需与 C1 的跳转／媒体范围分别冻结。自定义文件不进入默认发行资源。

进入实施前确定标签默认展开与顺序保存、索引／正文缓存生命周期，并用既有合法配对测量冷／热查询、内存及错误隔离；据测量固定预算。验收至少包含真实两词典查询、单词典故障、取消／新查询、未保存笔记保护、重启顺序恢复以及学习数据保持。完整扫描 CLI 时间不代替按需查询预算。

## D2：有来源的完整核心摘要

建议继续使用既有“逻辑引用＋微型兜底摘要＋独立笔记”：在新准入的默认词典中读取标准词头、已有音标／词性及简明义项，各字段保留来源和缺项。中文、英语、法语内容分别统计覆盖；义项选择与显示长度需按真实样本确认。旧记录的摘要和独立笔记不自动替换。

当前 FreeDict 小样与 Lexique 3.83 词频不提供完整 A1–B2 CEFR 词表；FLELex 的非商业限制不符合默认资源政策。完整词典和分级来源须先通过[许可／覆盖准入](development-readiness.md)，保留授权、固定快照、转换和体积证据。分级缺项保持未知，不从词频推断等级，也不采用约 100 字节硬限制。

进入实施前完成候选来源及三语字段的独立样本验证，再冻结摘要选择、版本更新和缺资源行为。验收包括缺项、同词多义、完整来源、超长内容、资源升级、旧记录保留与禁网重启。

## D3：已有动词范围的可靠原形关联

建议先使用[#38 已验收的完整动词表达](evidence/issue-38/README.md)与[#47 的明确词典关联](evidence/issue-47/README.md)。仅在资源给出可靠匹配且目标词典有对应原形时提供关联；多个候选由用户选择，无法确认时保留原查询与未知状态。不自动剥除代词、不把同形不同词性合并为唯一原形。

收藏沿用同一标准词头一份记录、Unicode 规范等价及只读来源锚点。词头的重音、大小写和撇号区别继续保留；词典升级不自动改写已保存身份、来源、摘要或复习状态。新增名词／形容词屈折及异写关系须先准入相应来源与覆盖。

进入实施前确认首片是否限于上述动词范围，冻结多匹配选择与缺失目标行为。验收使用普通／代词式、多个原形、同形歧义、缺失词条和升级后的真实资源；重复收藏、笔记、卡片、FSRS 与选定音频保持一致。
