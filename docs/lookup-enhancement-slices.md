# 查词增强的有界切片

2026-11-09，依据[暂存票 #9](https://github.com/zardonc/lexique/issues/9)。用户已确认 D1 多 MDX 标签与按需加载、D3 已有动词范围的可靠原形关联，两片已完成 [Windows x64 验收](evidence/issue-9/README.md)；D2 的完整词典／CEFR 来源继续保留准入门槛。#56–#59 已完成 Windows x64 检查。缓存及性能预算依据实测固定。D4 的真实 FSRS 排序继续沿用 #21／#22；C1–C4 不随本次范围整体采纳。

## D1：多 MDX 的首次产品接入

按用户的词典顺序显示标签，初次仅加载首个读取成功词典的正文，其余标签点击后加载。切换词典保留查询；单个词典缺失、损坏、不支持或无结果分别显示，其他词典仍可查询。每个结果保持自己的来源与文件版本，不合并物理 ordinal 或静默覆盖已保存摘要。

复用[已验收的 mdictlib 0.2.8 + LZO 支持矩阵](evidence/issue-3/README.md)，先限定已实测的 v1／v2、UTF-8／UTF-16 与压缩组合。原始 HTML／CSS／脚本不得获得 main 窗口原生权限；正文显示隔离需与 C1 的跳转／媒体范围分别冻结。自定义文件不进入默认发行资源。

验收覆盖标签默认选择与顺序保存、索引／正文缓存生命周期、真实三词典原生 IPC 查询、单词典故障、取消／新查询、未保存笔记保护、重启恢复及学习数据保持。完整扫描 CLI 时间不代替按需查询预算。

实施边界：顺序保存于独立 `app_metadata` 偏好，默认仅有现有 FreeDict 小样。用户通过文件选择导入 MDX，应用保留便携数据目录内的独立副本；最多 16 个词典。移出列表不删除文件或学习记录。初次按顺序尝试，选中首个读取成功的词典，空结果仍保持该标签；其他正文只在点击后读取。来源、原拼写与同键物理记录分别保留，记录编号在应用响应中使用从一开始的 ordinal。

复用 #3 的 128 MiB 文件、16 MiB 压缩／解压块、8 MiB 单条解码、1,000,000 记录和每解析器 256 MiB 预算。最多保留两个原生解析器，离开进程释放；长度／修改时间改变时丢弃对应缓存，文件摘要每次打开只计算一次，固定收藏来源版本。单查询最多 200 条、4 MiB 正文，超限明确报错。前端只缓存当前查询的已访问正文，换查询或离开页面释放；不建立持久正文或索引副本。

Windows x64 的既有 Heliknight、Robert、Larousse 文件按需基线：打开 5.96–15.63 ms，首个定位／正文查询 6.36–58.22 ms，重复查询 0.002–0.23 ms；打开时正文缓存为零，解析器峰值 0.51–5.43 MiB。这是冷解析器／热文件缓存测量，不是冷磁盘或进程 RSS。产品查询预算为首次 1,500 ms、复用缓存 250 ms，最终在原生 IPC 验证；完整扫描不参与计量。复现入口为 `tools/mdict-probe/examples/lookup-latency.rs`。

最终 Windows x64 语音便携包的原生 IPC 每份文件查询 `être` 21 次：首个查询 9.1／74.0／57.8 ms，缓存最大 3.0／3.0／3.9 ms，分别对应 Heliknight／Larousse／Robert。所有导入及正常重启通过，计量仅返回耗时、记录数和正文总字节；命令与完整边界见 [#9 证据](evidence/issue-9/README.md)。

正文采用无脚本、无同源权限的 sandbox iframe；仅保留显示所需的文字、格式与内联 CSS，移除跳转、媒体、活动元素和事件属性，并限制外部资源请求。隔离规则依据 [MDN sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox)，解析复用 [MIT mdictlib](https://github.com/lonelam/mdictlib)。C1 的重定向、词条内跳转及 MDD 媒体仍单独接入。MDX 的许可、音标、词性与释义字段未独立提取时保持未知；不自动把原始 HTML 当成中文兜底摘要。

## D2：有来源的完整核心摘要

建议继续使用既有“逻辑引用＋微型兜底摘要＋独立笔记”：在新准入的默认词典中读取标准词头、已有音标／词性及简明义项，各字段保留来源和缺项。中文、英语、法语内容分别统计覆盖；义项选择与显示长度需按真实样本确认。旧记录的摘要和独立笔记不自动替换。

当前 FreeDict 小样与 Lexique 3.83 词频不提供完整 A1–B2 CEFR 词表；FLELex 的非商业限制不符合默认资源政策。完整词典和分级来源须先通过[许可／覆盖准入](development-readiness.md)，保留授权、固定快照、转换和体积证据。分级缺项保持未知，不从词频推断等级，也不采用约 100 字节硬限制。

进入实施前完成候选来源及三语字段的独立样本验证，再冻结摘要选择、版本更新和缺资源行为。验收包括缺项、同词多义、完整来源、超长内容、资源升级、旧记录保留与禁网重启。

## D3：已有动词范围的可靠原形关联

使用[#38 已验收的完整动词表达](evidence/issue-38/README.md)与[#47 的明确词典关联](evidence/issue-47/README.md)。仅在资源给出可靠匹配且当前词典有对应原形时提供关联；多个候选由用户选择，无法确认时保留原查询与未知状态。不自动剥除代词、不把同形不同词性合并为唯一原形。

收藏沿用同一标准词头一份记录、Unicode 规范等价及只读来源锚点。词头的重音、大小写和撇号区别继续保留；词典升级不自动改写已保存身份、来源、摘要或复习状态。新增名词／形容词屈折及异写关系须先准入相应来源与覆盖。

本片限于上述动词范围。验收覆盖普通／代词式、多个原形、同形歧义、缺失词条、词典升级和来源移出后的操作重放；重复收藏、笔记、卡片、FSRS 与选定音频保持一致。
