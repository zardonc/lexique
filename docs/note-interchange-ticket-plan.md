# 生词笔记内容交换的交付切片与测试计划

2026-11-19。测试边界与拆分已确认，已发布[父规格 #183](https://github.com/zardonc/lexique/issues/183)及六个子 issue，均使用 ready-for-agent。各切片包含自身行为测试。

## 测试边界

以桌面笔记内容交换应用入口为主要边界，使用真实临时文件和真实 SQLite，核对预览、所选提交、重新打开、导出及完整备份／恢复结果。复用现有词汇保存、快照、备份与原生 WebView2／CDP 检查；文件选择可以替代，文件系统与数据库保持真实。浏览器验证映射、差异、排除、取消和错误展示；模拟 IPC fixture 不作为原生存储证明。

详细 T01–T40 用例及预期结果见同目录的 note-interchange-spec.md。测试覆盖 Unicode 和内容上限、字段缺失与空值、例句列表替换及来源、文件冲突、词典错误、事务回滚／修订冲突／重试、进度与分类保持、导出范围、ZIP 和跨格式往返。

S1 先交付规范单词文件的新建路径；已有同词内容相同可跳过，有差异显示并停止更新，完整选择更新由 S3 接入。单词文件可以包含多条例句。S4 补齐自动本地词典信息，最终功能不把所有新词默认保存为未关联。

S2 从现有已保存词汇导出，不依赖导入实现，适合与 S1 并行。S1 引入外部记录形态后，两条分支合并时导出仍须接受其空词典信息。S3 和 S4 可在 S1 后并行。S5 依赖 S3 的完整更新／提交语义，不依赖 CSV 导出。S6 依赖 S2 的范围／快照导出、S4 的完整词典结果处理、S5 的 Markdown 模板；这些都是其端到端 ZIP 能力实际复用的行为。

S1 涉及共享记录模型的实际调用者和学习快照，保留为一条完整的外部笔记链路；若实现时发现机械迁移无法在一个切片内保持检查通过，再按真实调用范围调整，当前不设额外预重构工单。
