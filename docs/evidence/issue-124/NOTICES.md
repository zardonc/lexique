# Issue #124 selected source notices

French adaptations and new English/Chinese explanations use **CC BY-SA 4.0**.
Complete legal text: [COPYING](COPYING);
[licence URL](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en).

Full linked article histories and the complete retained named/anonymous registry in
[source-context.json](source-context.json) supply contributor attribution. The
registries contain 3,291 named source/contributor entries; anonymous identities are
credited through each history. Registry membership is not sentence-level authorship.

DAF8-marked originals: **Académie française, Dictionnaire de l’Académie française,
eighth edition, 1932–1935**. The original collective work has the separately
recorded public-domain basis; subsequent wiki and Lexique contributions retain
CC BY-SA 4.0. Selected original/import boundaries and applicable authority text
are in [rights.json](rights.json) and [selected-rights.md](selected-rights.md).

Modifications: select one explicitly scoped use per exact group; remove wiki
markup; adapt the French definition; write EN/ZH explanations; select one
recorded isolated IPA and add slashes. Required construction, spelling and
register restrictions remain explicit. Unselected quotations, media, etymologies
and other-language meanings are retained only as audit context.
