# Windows x64 干净系统验收

此检查使用隔离测试数据，不需要用户安装 VC++ Redistributable。它验证指定的测试包，不代表其他架构或正式发行已通过。

1. 在干净 Windows 11 x64 上记录系统版本、是否已安装 Microsoft Edge WebView2 Runtime 和 VC++ Redistributable。不要卸载现有系统组件来制造测试环境。若缺少 WebView2，在联网设备从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)获取 x64 Evergreen Standalone Installer，传到测试机，由用户自行安装。记录版本和安装包大小；不把它放入 Lexique 包。
2. 将交付 ZIP 复制到测试机，核对随附 `.sha256`，解压到可写目录。关闭网络，保留系统 WebView2。启动 `Lexique.exe`，记录是否需要安装其他运行库或出现 DLL 错误；不要添加系统 VC++ 运行库来掩盖失败。
3. 查找并收藏 `école`、`bonjour`，打开自动加入复习。生成并播放听音卡，分别评分识义卡和听音卡；修改例句与设置、暂停和恢复，并检查队列及每日额度。记录失败信息和截图，勿包含个人学习数据。
4. 退出应用，将整个解压目录移到新的可写位置，重新启动；检查词条、例句、设置、卡片进度、队列、额度和撤销目标。撤销后确认后来独立收藏和设置仍在，额度返还。再次生成和播放语音。
5. 如需验证缺 WebView2 提示，在另一个尚未安装该运行时的隔离环境操作；不要更改日常使用机器。根据 ZIP 内 `README.txt` 获取官方运行时并自行安装，然后重试。
6. 返回系统版本、WebView2 和 VC++ 状态、ZIP SHA-256、每一步结果及错误信息。音频实播请记录是否听到清晰的法语发音。保留测试目录以便定位失败。

评分／撤销写入失败和批量部分失败由仓库隔离自动化验证；此人工检查不能代替这些故障注入检查。禁网必须覆盖生成、播放、重启和移动，不要仅凭未主动联网推断断网。
