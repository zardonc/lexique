## 接受标准（运行前记录）

- V01：现有 UI / RuntimeAdapter 的固定阻塞序列重现导航禁用及后词建卡被首词语音阻塞。真实 Windows IPC 单独测进入队列、评分、缓存读取／播放、查词及交互试音；模拟 IPC 时间只用于回归控制，不当原生性能。
- V02：沿用已准入 Supertonic 3 int8 / sherpa-onnx 2.0.1，CPU、法语、8 步、48 kbit/s、2 推理线程。比较后台 1／2／4 + 独立保留的 1 个 P0 名额、默认／关闭空转；单模型共享失败才增加双模型进程。每配置三轮，12 个固定单词、男女声，固定种子对照另验现有随机路径。P0 不排在全批次尾部，热 P0 完成中位数不超过串行同样 P0 的 1.5 倍且最大值不超过 3 秒；采样私有提交量不超过 1.5 GiB，工作集不超过 1 GiB。完整进程与冷加载、预热、服务／排队、CPU／内存分别记录；每次执行 60 秒硬限。数值／格式／完整解码通过不替代人工法语音质。
- V03：比较 20／50／100 词短事务及逐词 savepoint，单事务持锁最大值 100 ms、并发笔记／评分等待最大值 250 ms，未达到则缩小 chunk 后重测。页容量与事务规模分别决定。真正提交后才返回成功；唯一性、非法／未知 ID、逐词失败、commit 失败、重复／丢响应重试、既有进度／暂停均须验证。生成等待期间用户库可写；不新增独立库或 BLOB。
- V04：时间统一为 UTC Unix 秒，`expires_at = generated_at + 604800`，`now >= expires_at` 拒用临时资产；生成完成并发布核验后登记时间，访问不续期。语义键 SHA-256 覆盖完整 NFC 文本、语境、语言、引擎／模型／前处理版本、实际声线、合成参数和编码，归属／播放速度不入键；文件内容另存 SHA-256。任一生词归属持久保护单词，不要求听音卡；例句仍临时。最后归属删除、旧模型／声线文件均保留，不自动全库重生成。旧 ID 音频只在核验后增量登记为 legacy，不推测其真实声线／模型或生成时间；未知生成时间保持兼容且不参加 TTL GC。登记失败回滚，旧文件不动。GC 清理前再次核验归属、使用和版本，仅删除已到期且无保护的明确管理资产。
- V05：受控 worker／时钟／transport 只验证协议和调度。固定 queued／running／retry_wait／ready／failed／cancelled，合并同语义需求、P0 提升、后台名额上限／保留 P0、queued／retry_wait 取消、运行项安全完成、超时／worker 退出、发布后提交前崩溃恢复、attempt／取消跨重启均须验证。首次加三次重试最多四次，2／8／20 秒与 Retry-After 取较大值，总预算耗尽停止；未配置在线调用为零，繁忙不触发在线。实际磁盘原子发布及退出另运行原生边界检查。当前 Supertonic 在途合成不可抢占；进程级终止只能报失败，不能报已取消成功。
