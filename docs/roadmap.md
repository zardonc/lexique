## 阶段范围

1. 资源可行性与原生构建验证：落实项目 MIT 与默认资源的分别许可，核查内置词典 / 变位 / 词表 / TTS 的许可和覆盖；验证原生构建与关键资源组合的可行性，明确最低 macOS 和四架构依赖。包体计量及 Windows WebView2 离线依赖策略已确认，细节和准入门槛见 [开发准备清单](development-readiness.md)。内置词典与变位可在许可允许时转换为只读结构化资源，自定义 MDX/MDD 支持保留。
2. 第一条真实链路：离线查询 → 创建笔记 → SQLite 保存 → 关闭并重启后恢复。先确认笔记、分类、卡片模板与导入导出字段；以原型的交互为参考，以真实数据与失败状态为验收依据。
3. 复习核心：先验证固定 FSRS 候选、原生 / 实际 WASM 一致性及听音卡所需单词离线语音的可行性，再接完整持久化、评分 UI 与撤销；保留必要日志与完整状态快照。
4. 完整离线核心：已完成 Windows x64 约定变位反查、全部匹配及逐表达 Supertonic 3 发音；首期新增系统选词、屏幕 OCR、词频颜色及共用 WPM，按上述切片完成，继续补齐词典／分级和其他离线模块。
5. 外部能力与同步：安全保存用户凭据，接普通翻译 / OpenAI 兼容服务；先冻结跨云文件协议、事务 outbox、冲突 / 删除 / 恢复规则，再分阶段交付 Google Drive、OneDrive 后台批量同步与可验证清理，数据查看和修改均在应用内完成。
6. 桌面发行验收：Windows 按免安装 portable 交付并验证 `.exe` 同级数据目录、移动与重启；macOS 的分发方式单独确认。验证四架构首装禁网和完整默认资源包体积，以及签名、公证与发行资源声明。
7. 第二阶段：新增移动浏览器复习应用与必要 BFF，实际调用 WASM FSRS；先验证 IndexedDB 的业务状态 / outbox 原子提交与强关恢复，再接同一文件协议、授权、限流 / CSRF 与跨设备进度。听写 / 自定义文章 / 可选翻译模型按单独批次交付。

每条真实链路在实现前列出失败场景，开发中运行 lint / typecheck，结束时运行完整 E2E 并保留截图、导出或数据库回读证据。后端测试先编译，执行阶段硬性 60 秒超时。禁止用“没有测试可运行”当作通过。

M3 变位的逐项范围、23 区块矩阵和着色模式保持已确认的[变位范围](m3-conjugation-scope.md)。2026-11-07，[实施规格 #38](m3-conjugation-spec.md)的 #39–#49 已完成约定的 Windows x64 验收：匹配格式 6 的新鲜 TTS 包获用户断网通过，完整表达反查／发音、三种着色和持久排序、双向词典导航及学习数据保持有实际原生证据。全资源覆盖、紧凑存储等价性、CLI 预算及边界见 [#38 收尾](evidence/issue-38/README.md)。其他 M3 模块、其他平台实机和 M5 正式发行继续按各自门槛执行。

2026-10-25 M2：Q1–Q42 已逐项确认，完整规则与核对来源见[M2 确认稿](m2-review-core.md)，随后已发布[规格和工单](m2-ticket-plan.md)。同词的识义卡与听音卡分别保留进度，见 [ADR 0005](adr/0005-independent-progress-for-vocabulary-card-types.md)。支持生词本单个 / 批量加入、暂停与恢复；收藏自动加入默认关闭且不追溯。重复收藏、再次加入或音频重试不重置进度，也不解除主动暂停。卡面精简，共用可编辑例句；只有法语或中文也可保存并标“待补例句”，继续允许复习。

调度首选验证候选为 `fsrs-rs v6.6.2`，使用固定版本默认参数、不提供优化与额外间隔随机扰动；保持率 70%–99%、默认 90%，修改仅作用于后续评分。学习日以本地凌晨 4 点为界，旧到期时间保留为实际时间点；长期间隔取整为 1–36,500 天，在目标学习日凌晨 4 点到期，分钟步骤按完整实际间隔，见 [ADR 0006](adr/0006-learning-days-and-absolute-review-times.md)。时钟倒退至最近评分之前时暂阻评分并提示，保留历史。

每日额度按用户后续决定采用三项设置：新卡上限（现有默认 20）、复习上限（现有默认 50）及新卡是否忽略复习上限（默认关闭）。新卡首次成功评分计数；跨日学习和长期复习占复习额度，日内学习重复不占额度；跨日学习优先纳入。两项数值可设为 0，当天修改保留已用次数。到期分钟级学习优先，不提前学习；同词另一张卡不因评分而暂缓，仍遵守到期、音频和额度限制。队列及一级评分撤销须跨重启恢复，撤销返还原评分的额度影响；生词本按同词已学习卡最早的原始到期时间排序。

单词离线发音与播放提前到 M2，完整变位及例句朗读仍属 M3。#13 原生 / 实际 WASM 验证与 #14 Windows x64 单词语音准入已完成。#15–#21 已接入单个生词双卡、离线语音、独立评分与排程、完整队列、一级撤销、管理、共享例句及下次复习排序。2026-11-01，#22 的 Windows x64 / 实际 WASM 综合检查通过，用户确认全新 Windows 断网功能正常，并明确 macOS 验收留待后续、不阻塞继续开发；未发现其他阻塞问题，按用户授权完成 #22 验收。完整证据及限制见 [#22 收尾报告](evidence/issue-22/review-2026-11-01.md)。macOS 编译/实机与其他架构实机仍待验证，既有 macOS M1 blocked 清单和 M5 四目标正式发行门槛继续保留。

## M4 / M6 同步规划补充（2026-11-02）

此次方向替代早期可人工编辑 Sheets 的双向方案，保留既有阶段顺序。[同步设计](sync-design.md)给出 SQLite + JSONL 的综合评估、来源依据、冲突与故障矩阵；正式跟踪沿用[总规格 #1](https://github.com/zardonc/lexique/issues/1)。以下为后续拆票顺序建议，尚未实施或冻结全部默认值。

| 批次 | 可审查的交付结果 | 验收门槛 |
| --- | --- | --- |
| M4-S0 | 文件协议、共享范围及故障样例 | 稳定身份 / generation、因果与同词冲突、额度、来源认证、成员 / epoch；CSV / XLSX 作为查看导出 |
| M4-S1 | 所有本地业务写入的事务 outbox 与已有数据接入 | SQLite 实际持久配置；确认后禁网强关 / 重启仍有业务及待发操作，非破坏迁移 |
| M4-S2 | 双副本不可变分段、最后发布清单、去重与冲突裁决 | 缺口 / 乱序 / 半文件、上传中继续学习、结果不明重试、评分 / 撤销分支不丢失 |
| M4-S3 / S4 | Google Drive 首条真实批量链路，再复用协议接 OneDrive | 各自授权、对象身份、发现 / 分页、配额、条件 / 冲突写入及故障恢复；不得逐次评分请求网盘 |
| M4-S5 | 一致检查点、滚动 GC、设备退役及跨云恢复 | 持久 ack / rebase、上一基线及增量链、可信替代元数据、历史保留；离线设备与分叉阻止不安全清理 |
| M6-B1 | IndexedDB 宿主 + 实际 WASM 的持久评分 | 事务完成后确认、多标签页、配额 / 私密模式 / 升级 / 强关；无法持久化时保持真实能力限制 |
| M6-B2 | 浏览器与桌面使用同一协议会合 | OAuth / BFF / 会话 / CSRF、后台挂起、跨端冲突 / 额度及退役回归；不能依赖页面关闭时上传 |

自动间隔、分段大小和压缩阈值为待压测参数；五分钟限频与 4 MiB / 2,000 操作仅是设计起点。单设备快照可作为先行备份，但不能据此宣布多设备同步完成。可选音频共享另遵循 [#24 研究](evidence/issue-24/concurrency-batch-web-research.md)，不混入文本 outbox，也不提前宣称浏览器音频已可用。
