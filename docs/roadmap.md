# 开发路线

这是骨架后续的实施顺序，不代表功能已完成或工期已承诺。

1. 资源与发行边界：确认项目许可证、内置词典 / 变位 / 词表 / TTS 的许可和覆盖；明确最低 macOS、包体计量和四架构依赖。
2. 第一条真实链路：离线查询 → 收藏 → SQLite 重启可恢复。先确认笔记、分类、卡片模板与导入导出字段；以原型的交互为参考，以真实数据与失败状态为验收依据。
3. 复习核心：选定 FSRS 实现，保留必要日志与完整状态快照，用固定输入验证桌面和 WASM 的一致性，再接 UI 评分与撤销。
4. 完整离线桌面：接变位反查、所有匹配高亮、真实离线 TTS；验证四架构安装器、首装禁网和完整资源包体积。
5. 外部能力与同步：安全保存用户凭据，接普通翻译 / OpenAI 兼容服务；先确认冲突与删行规则，再实现 Google OAuth、Sheets 同步及失败恢复。
6. 第二阶段：新增移动浏览器复习应用与必要 BFF，实际调用 WASM FSRS，验证授权、限流 / CSRF 与跨设备进度。听写 / 自定义文章 / 可选翻译模型按单独批次交付。

每条真实链路在实现前列出失败场景，开发中运行 lint / typecheck，结束时运行完整 E2E 并保留截图、导出或数据库回读证据。后端测试先编译，执行阶段硬性 60 秒超时。禁止用“没有测试可运行”当作通过。
