# 开发路线

2026-10-24 用户确认以下开发顺序，不代表功能已完成或工期已承诺。中间里程碑用于开发验收；桌面正式发行仍需满足已确认的默认词典、完整约定变位及四平台离线语音要求。2026-10-26 调整为每个平台同时提供内嵌模型的完整版和可由用户下载模型的 Lite 版；两版均尚未发行。

1. 资源可行性与原生构建验证：落实项目 MIT 与默认资源的分别许可，核查内置词典 / 变位 / 词表 / TTS 的许可和覆盖；验证原生构建与关键资源组合的可行性，明确最低 macOS 和四架构依赖。包体计量及 Windows WebView2 离线依赖策略已确认，细节和准入门槛见 [开发准备清单](development-readiness.md)。内置词典与变位可在许可允许时转换为只读结构化资源，自定义 MDX/MDD 支持保留。
2. 第一条真实链路：离线查询 → 创建笔记 → SQLite 保存 → 关闭并重启后恢复。先确认笔记、分类、卡片模板与导入导出字段；以原型的交互为参考，以真实数据与失败状态为验收依据。
3. 复习核心：先验证固定 FSRS 候选、原生 / 实际 WASM 一致性及听音卡所需单词离线语音的可行性，再接完整持久化、评分 UI 与撤销；保留必要日志与完整状态快照。
4. 完整离线核心：接变位反查、所有匹配高亮、真实离线 TTS。
5. 外部能力与同步：安全保存用户凭据，接普通翻译 / OpenAI 兼容服务；先确认冲突与删行规则，再实现 Google OAuth、Sheets 同步及失败恢复。
6. 桌面发行验收：Windows 按免安装 portable 交付并验证 `.exe` 同级数据目录、移动与重启；macOS 的分发方式单独确认。验证四架构首装禁网和完整默认资源包体积，以及签名、公证与发行资源声明。
7. 第二阶段：新增移动浏览器复习应用与必要 BFF，实际调用 WASM FSRS，验证授权、限流 / CSRF 与跨设备进度。听写 / 自定义文章 / 可选翻译模型按单独批次交付。

每条真实链路在实现前列出失败场景，开发中运行 lint / typecheck，结束时运行完整 E2E 并保留截图、导出或数据库回读证据。后端测试先编译，执行阶段硬性 60 秒超时。禁止用“没有测试可运行”当作通过。

2026-10-25 M1 访谈补充：采用现有 FreeDict 小样验证“逻辑引用 + 微型兜底摘要 + 独立笔记”的同词一份记录，以及查词摘要置顶、原文 / 笔记分开、收藏状态联动与重启恢复。[保存规则](m1-note-saving.md)已逐项确认，包含搜索、三种字段排序与偏好恢复、重复收藏及编辑冲突处理；正式规格为 [#10](https://github.com/zardonc/lexique/issues/10)。资源测试后的多词典、完整摘要、词形反查与 M2 复习日期排序见[后续需求暂存](deferred-lookup-requirements.md)，明确不纳入 #10。

2026-10-25 M1 当前状态：Windows x64 的本地链路及 release portable 已验证，见[验证记录](verification.md#m1-windows-复盘修复与-macos-阻塞)。macOS 专属编译、退出保护与恢复验证仍为 **blocked — 等待 macOS 执行环境**，后续按[阻塞清单](macos-m1-blockers.md)集中执行；Windows ARM64 仅编译通过。下述 M2 规则来自独立访谈，不因 Windows M1 通过而宣称 M2 或完整发行就绪。

2026-10-25 M2：Q1–Q42 已逐项确认，完整规则与核对来源见[M2 确认稿](m2-review-core.md)，随后已发布[规格和工单](m2-ticket-plan.md)。同词的识义卡与听音卡分别保留进度，见 [ADR 0005](adr/0005-independent-progress-for-vocabulary-card-types.md)。支持生词本单个 / 批量加入、暂停与恢复；收藏自动加入默认关闭且不追溯。重复收藏、再次加入或音频重试不重置进度，也不解除主动暂停。卡面精简，共用可编辑例句；只有法语或中文也可保存并标“待补例句”，继续允许复习。

调度首选验证候选为 `fsrs-rs v6.6.2`，使用固定版本默认参数、不提供优化与额外间隔随机扰动；保持率 70%–99%、默认 90%，修改仅作用于后续评分。学习日以本地凌晨 4 点为界，旧到期时间保留为实际时间点；长期间隔取整为 1–36,500 天，在目标学习日凌晨 4 点到期，分钟步骤按完整实际间隔，见 [ADR 0006](adr/0006-learning-days-and-absolute-review-times.md)。时钟倒退至最近评分之前时暂阻评分并提示，保留历史。

每日额度采用方案 B：新卡首次评分默认 20 张，其余成功评分（含初学 / 重学重复）另计 50 次，两项独立、可设为 0，当天修改保留已用次数。到期且额度允许的分钟级学习优先，新卡按比例穿插旧卡，不提前学习；同词另一张新卡 / 长期卡暂缓至下一学习日。队列及一级评分撤销须跨重启恢复，撤销返还原评分的额度影响；生词本按同词已学习卡最早的原始到期时间排序。

单词离线发音与播放提前到 M2，完整变位及例句朗读仍属 M3。#13 原生 / 实际 WASM 验证与 #14 Windows x64 单词语音准入已完成。#15 已接入单个生词建双卡、语音生成 / 卡面和 Windows x64 重启恢复；原生实播及自动回归通过，新音频由用户试听，具体结果与限制见 [#15 证据](evidence/issue-15/README.md)。#16 接入单卡四档评分、真实排程和事务恢复，验证及限制见[验证记录](verification.md)。完整队列、撤销与管理仍待后续，M2 未完成。其他目标的实机运行及最终发行许可和完整包体仍待验证，不降低既有 macOS 阻塞及 M5 四目标发行门槛。
