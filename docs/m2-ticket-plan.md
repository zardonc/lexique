## T01：验证固定 FSRS 核心、学习步骤与原生 / 实际 WASM 一致性

**Blocked by:** None。

**What to build:** 从固定输入及时间上下文出发，经同一个公开调度入口，在原生与实际加载的 WASM 中得到可比较的记忆状态、阶段及到期时间。先交付可重复执行的验证链，不做用户库迁移或完整复习界面。

- [x] 固定 fsrs-rs v6.6.2、官方默认模型参数与许可；记录工具链、依赖、原生 / WASM 产物体积及复验命令。不可用时报告，不静默换库。
- [x] 覆盖四档评分、全部初学 / 重学步骤、每次评分对应的记忆状态、长期取整及 1–36,500 天边界；不增加间隔扰动或参数优化。
- [x] 验证保持率默认 90%、70%–99% 端点与非法输入；历史输入使用当时版本、参数和保持率。
- [x] 固定向量覆盖凌晨 4 点、同日 / 跨日、夏令时、换时区、分钟完整间隔、已有绝对到期时间及时间倒退的拒绝行为。
- [x] 实际执行 WASM 排程；记忆数值容差有实测依据，阶段、步骤秒数、整数间隔及到期日严格相等。版本 ABI 成功不算通过。

2026-10-28 验收通过，使用显式数学兼容修订；完整命令、审查与未验证平台见[#13 收尾记录](evidence/issue-13/closeout-2026-10-28.md)。

## T02：完成 M2 单词离线语音组合的准入与实播验证

**Blocked by:** None。复用 #5–#7 的候选证据，不要求三个候选全部完成；仅至少一个完整组合通过才解除本票对后续集成的阻塞。

**What to build:** 在 Windows x64 将真实法语单词离线生成为音频并播放，交付可供桌面产品接入的已验证组合与资源清单。

2026-10-28：#14 已关闭；用户接受的证据缺口、试听结果及发行限制见[准入决定](evidence/issue-14/README.md)。以下保留发布时的原始验收条目，完整产品发行与其他平台验证仍待后续工作。

- [ ] 核对已有候选证据，补齐所选引擎、模型、声线、文本 / 音素前端、运行库及配套文件的版本、哈希、来源和各自转换 / 再分发许可，不重复建设三套候选工具。
- [ ] 复用既有统一法语样本，补足未知词与孤立短词，保留准确输入；实际禁网生成有效音频并真实播放，不用缓存或预生成文件冒充。
- [ ] 交付可试听样本、质量结果和未知词失败行为；需要用户试听判断时明确记录，未确认前不宣称质量通过。
- [ ] 测量完整压缩下载量、安装量及必要系统依赖，记录性能与硬件而不发明阈值。2026-10-26 用户决定完整版内嵌模型、不受 200 MB 上限限制；另提供用户主动下载 TTS 模型的 Lite 版，其他资源保持内置，发行实现由后续里程碑完成。
- [ ] 记录其余三个目标的构建 / 获取路线与未实机验证空缺；不扩展到完整变位或例句朗读，不代替 M5 发行验收。

## T03：从单个生词创建双卡、生成语音并在重启后查看卡面

**Blocked by:** T01、T02。

**What to build:** 学习者从生词详情加入复习，看到识义卡和听音卡及音频状态；重启仍保留两卡身份和内容。此票完成建卡和卡面，评分由 T04 接入。

- [ ] 增量迁移保留 M1 生词、摘要、来源、笔记；失败回滚，高版本拒绝，升级不批量建卡。同词同类型最多一张卡。
- [ ] 单个加入打通界面、原生接口、用户库与已准入离线语音。重复点击、丢响应和重启重试不重复建卡、覆盖进度或解除暂停。
- [ ] 语音生成失败仍保存两卡，识义可用、听音待生成且不可评分；再次加入只重试缺失 / 失败音频。用户看到真实错误，不把部分成功显示为全成功。
- [ ] 识义正面显示词头，听音正面不泄露文字、进入自动播放一次、可重播、翻面不自动播放；背面显示摘要释义，缺例句明确提示，更多笔记 / 来源按需展开。
- [ ] 已有音频播放失败提示重播 / 跳过，本次未成功播放不得评分；跳过不改排程或计数。通过原生实播及公开存储 / 界面边界验证重启恢复。
- [ ] 生成音频保存在 portable 数据目录的专用临时目录并按[架构约束](architecture.md)定期清理；验证过期、使用中、重启 / 移动、清理失败和缺失后重试，确认模型、其他资源、学习数据与进度不受影响。

## T04：完成单卡四档评分、真实排程与事务恢复

**Blocked by:** T03。

**What to build:** 学习者翻面后给一张识义卡或听音卡评分，卡片按真实学习步骤 / FSRS 到期，再次打开继续；不是只写调度接口。

- [ ] 接入四档评分及含义提示，展开前不可评分；听音另受本次成功播放约束。两类卡独立记忆状态和排程。
- [ ] 评分原子保存前后状态、有效历史、版本 / 参数 / 保持率及时间上下文、经过天数、额度影响、同词暂缓及已有队列变化，足以支持 T06 撤销；失败保留当前卡与错误。
- [ ] 首条链路即遵守默认独立 20 张新卡 / 50 次其他作答额度，分钟重复也计数；操作重试不重复评分或扣额。时钟倒退暂阻评分，生词仍可查看。
- [ ] 同词另一张新卡 / 长期卡暂缓至下一学习日，分钟步骤例外；不改写另一张卡原始到期时间。
- [ ] 未到期不提前评分，显示等待并可结束本轮；真实重启保留进度、必要日志 / 快照、已用额度与已建立队列，不在重启时重排。
- [ ] 覆盖评分事务回滚、丢响应重试、并发旧状态拒绝、两卡独立及跨日；适用核心向量、真实 SQLite、界面和原生验证随票交付。

## T05：交付每日设置、混合队列与跨重启出卡顺序

**Blocked by:** T04。

**What to build:** 多个生词按学习日、额度、同词暂缓与到期优先规则组成真实队列，学习者可调整每日负担和保持率。

- [ ] 设置持久化目标保持率 70%–99%、步长 1%、默认 90%，两卡共用；改变仅影响后续评分，历史及旧到期时间保留。
- [ ] 两项额度默认 20 / 50、独立且可为 0；当天改上限保留已用次数，剩余最低为 0。学习日切换才重置，不因重启重置。
- [ ] 到期且额度允许的分钟学习优先，按实际入队新旧卡数量比例均匀穿插；旧卡按到期学习日、同日打乱，新卡按加入顺序。
- [ ] 刷新 / 重启保持已有顺序，动态按到期与最新设置判断准入；同词暂缓不覆盖原始排程，分钟步骤仍受额度约束。
- [ ] 区分本轮完成、未到期等待和额度耗尽，提供相应提示；设置与队列变化不得破坏 T04 原子评分或 T06 所需恢复信息。
- [ ] 使用固定时间和可复现队列验证混排、额度上下调 / 零、跨学习日、重启、同词暂缓及分钟例外。

## T06：跨重启撤销最近一次评分并返还原学习日额度

**Blocked by:** T05。

**What to build:** 学习者误评分后可立即或重启后撤销一次，恢复真实出卡与额度，继续复习。

- [ ] 仅保留一级撤销，原子恢复该评分影响的记忆状态、阶段、到期时间、同词暂缓及队列变化。
- [ ] 返还原评分对原学习日的额度影响；跨日撤销不错误增加当前日额度。
- [ ] 保留评分后的独立笔记 / 例句与设置修改；检测并发修改，不以旧快照覆盖新状态。
- [ ] 重复点击、丢响应及重启重试不重复撤销或重复返还额度；失败保留可恢复状态并提示真实错误。
- [ ] 公开存储与界面测试覆盖新卡 / 分钟步骤 / 长期评分、重启和跨日，真实原生演示撤销后继续学习。

## T07：批量管理复习、收藏自动加入与暂停恢复

**Blocked by:** T05。

**What to build:** 学习者从当前搜索结果批量加入、暂停或恢复复习，并选择是否让今后新收藏自动加入。

- [ ] 单选 / 多选及全选当前搜索结果；搜索变化清空选择，排序变化保留已选单词；批量逐词显示成功 / 失败，可安全重试。
- [ ] 收藏自动加入默认关闭，只作用于开启后新收藏；开启不追溯，关闭不删卡或暂停，重复收藏不改进度。收藏成功与后续音频失败分别真实反馈。
- [ ] 单个 / 批量暂停作用于同词两卡，保留进度与历史；恢复沿原排程且遵守额度、音频可用性及同词暂缓。
- [ ] 加入与音频重试均不解除主动暂停，不因批量操作重建卡片或重复计数；队列及时反映变化并跨重启恢复。
- [ ] 覆盖批量部分失败、重复操作、设置重启、暂停后重试音频和恢复到期卡；不让后续撤销覆盖独立管理操作。

## T08：编辑共享法中例句并在两类卡显示完整或待补状态

**Blocked by:** T03。

**What to build:** 学习者在生词详情补充或修改复习例句，明确保存后两类卡共用，缺项也能继续复习。

- [ ] 例句 / 中文译文与独立笔记分开，默认卡面显示对应某个展示释义的一组例句，更多例句按需展开；不改变只读兜底摘要。
- [ ] 法语单独、中文单独、两者都缺或完整均有真实显示；缺项标待补例句，允许保存并复习，不生成假内容。
- [ ] 沿用明确保存、离开提醒和修订冲突保护；失败保留输入，重复提交安全，重启恢复已保存内容。
- [ ] 两卡共用编辑结果且进度不重置；资源更新不覆盖用户修改，用户内容与资源来源分别表达。
- [ ] 内置例句只使用许可 / 质量已验证内容并保留来源；无合格内容时保留缺项与用户补充路径，不引入 AI 或将全量例句资源变为门槛。
- [ ] 验证不同语言缺项、冲突 / 失败 / 离开及双卡展示，并与评分 / 撤销的内容保留要求相容。

## T09：按真实下次复习时间排序生词本

**Blocked by:** T04。

**What to build:** 学习者在生词本按同词已学习卡最早原始到期时间排序，并在评分后及重启后看到真实结果。

- [ ] 已学习卡最早原始到期优先；尚未学习的记录随后，未加入复习的最后，同时间按词头稳定排序。
- [ ] 同词暂缓、暂停及额度不改写这个时间；时区只调整显示，不移动已有排程。
- [ ] 沿用生词本搜索与排序偏好恢复；不存在的排程不生成模拟日期，不改变其他既有排序。
- [ ] 真实 SQLite 与界面验证双卡不同到期时间、缺失进度、同时间、重启及评分后刷新；T10 补验与撤销 / 暂停 / 批量选择的最终组合。
- [ ] 在子票中引用 #9 的 D4 来源，不扩大至其余查词增强，也不修改或关闭 #9。

## T10：完成 Windows x64 离线复习全链路与 M2 证据验收

**Blocked by:** T06、T07、T08、T09。T01–T05 均为这些票的传递前置，不重复加边。

**What to build:** 用真实 Windows x64 portable 与实际 WASM 完成最终验收，交付可核验的 M2 状态及其平台边界，修复本范围集成问题。

- [ ] 在隔离测试用户数据下完整演示离线加入 / 音频生成及播放、双卡独立评分、每日额度 / 混排 / 同词暂缓、暂停恢复、例句编辑、排序及一级撤销。
- [ ] 禁网重启与移动 portable 后恢复学习数据、设置、队列、额度和撤销；验证音频生成 / 播放失败、部分批量失败与重试不损坏进度。
- [ ] 验证评分后的例句 / 设置 / 管理操作与撤销交互；评分或撤销失败不虚报成功，不以旧快照覆盖独立操作。
- [ ] 运行适用前端、后端、E2E、实际 WASM 及 portable 工具检查；预编译后端再执行硬 60 秒测试，停止本次测试进程。
- [ ] 记录真实 Windows x64 运行与实际 WASM 向量、法语试听、资源许可 / 哈希、主包和依赖及完整离线压缩体积；未满足语音准入不得报告 M2 全部通过。
- [ ] 其他目标继续编译检查，实际运行分别标未测 / 阻塞；保留 macOS M1 阻塞及 M5 四目标正式发行门槛，不将本票通过等同发行就绪。
