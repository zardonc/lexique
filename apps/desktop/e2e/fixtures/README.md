# Conjugation browser fixture

`conjugation.json` contains the unmodified source cells and verb metadata returned by the pinned public resource CLI for `sommes`, `suis`, `paie`, `falloir`, `enfuir` and `voilà`. Only the desktop response fields are retained. Test assertions use literal expectations from the confirmed specification and the independently checked examples in the [resource evidence](../../../../docs/evidence/issue-39/README.md).
