# Syntactic admission and subject elision

The pinned [official Lefff repository](https://gitlab.inria.fr/almanach/alexina/lefff), commit `a0feecc2bb09730601fee0213e804fb03143f7b5`, supplies ordinary/pronominal frames, auxiliary macros and explicit morphology availability. `v_new.ilex` takes precedence; `v.ilex` and `v-phd.ilex` supply positive ordinary frames when that use is absent from the newer file. All entries retain their provenance. The `@pron` macro distinguishes obligatory pronominal frames; stale or optional `se` display text alone does not exclude an ordinary object frame. Gzip packaging is lossless. All other upstream files retain their exact bytes, including the LGPL-LR `LICENSE` and attribution `README`. The project website now advertises CeCILL-C; these pinned files explicitly carry LGPL-LR, which is the license used here.

`morpho.fr` and `v_new.mf` establish defined blocks, including infinitive-only and defective patterns. Lexique reads their tags and inheritance without executing upstream code or implementing its phonological compiler. Four omitted regular present participles use the literal `v-er` suffix `ant`; original Lefff rows and unspecified agreement dimensions remain intact. `@être` and `@être_possible` select être or both auxiliaries in ordinary frames; other ordinary frames use avoir, consistent with the source's lexical exception encoding and the [OQLF auxiliary rules](https://vitrinelinguistique.oqlf.gouv.qc.ca/24584/la-grammaire/le-verbe/auxiliaires/tableau-synthese-de-lemploi-des-auxiliaires-avoir-et-etre). Older usage labels enrich an already admitted auxiliary without introducing another one. Cited per-verb corrections take precedence, including modern être-only rester. Pronominal frames never license ordinary compounds. A cited positive ordinary form takes precedence over an omission in another reference: corrections retain rare occire future/conditional, choir auxiliaries/imperatives, and the falconry-only paître participle/compounds. Historical avenir is explicitly labelled, restricted to third persons, and projected through the already licensed venir morphology model, with cited historical spelling variants retained. This is a stated reference policy, not a claim that every dictionary agrees.

The `rosaenlg-*` files retain the original [RosaeNLG french-contractions](https://github.com/RosaeNLG/rosaenlg/tree/master/packages/french-contractions) reference sources, license and README; the exact commit is in `provenance.json`. Its aspirated-h list derives from Wikipedia and remains CC BY-SA 3.0, with the upstream license text and attribution preserved. Reference code is Apache-2.0; the upstream README declares CC BY 4.0. Lexique reads the list as data and applies it by lemma so inflected forms retain the verb's lexical behavior. Its y-before-vowel distinction is projected without executing upstream code. [Canada's elision guidance](https://nos-langues.canada.ca/fr/cles-de-la-redaction/elision) independently checks `j’habite`; [Bescherelle](https://bescherelle.ca/phonetique/elision-devant-h-muet/) checks `je hais`. These sources support subject expressions; query typography normalization remains separate.
