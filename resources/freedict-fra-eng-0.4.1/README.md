# Offline English verb meanings

The official [FreeDict French-English 0.4.1 source release](https://download.freedict.org/dictionaries/fra-eng/0.4.1/) contains 8,505 TEI entries. The source archive and official SHA-512 are pinned in provenance.json; its complete original TEI, header attribution, AUTHORS and GPL-2.0-or-later COPYING accompany every generated resource. Copyright belongs to its particular authors/compilers, including Horst Eyermann, Michael Bunk, John Darrington and the FreeDict project. Lexique code remains MIT; this content retains its original license.

The active [FreeDict dictionaries project](https://github.com/freedict/fd-dictionaries) supplies the upstream TEI representation and maintained conversion conventions. Lexique reuses its existing standard-library XML/archive resource pattern; no upstream executable code runs. Only explicit v/vi/vt entries and translation citations are admitted. Nouns sharing a verb spelling, French example citations and multiword phrases that do not exactly identify a conjugation lemma are excluded. No stemming, accent stripping or translation service is used.

Ordinary headwords match exact admitted ordinary lemmas. An explicit se / s' / s’ prefix maps to the exact remaining lemma with a separate pronominal label and original headword. Pronominal-only conjugation identities do not inherit bare ordinary senses. Source entry and sense ordinals, translation alternatives and source usage labels remain separate from Lefff morphology provenance. Source-only taire translations describe a reflexive use (compare [Le Robert](https://dictionnaire.lerobert.com/definition/taire)), so that bare entry is excluded; explicit se taire remains available. The retenir source sense 6, thunder, is excluded as a misplaced retentir sense (compare [Académie retentir](https://www.dictionnaire-academie.fr/article/A9R2200)); other retenir senses remain available. The historical verb avenir never inherits the noun's English future. Missing translations remain unavailable and do not affect conjugation tables. This small legacy resource provides partial English coverage, not a complete dictionary or certification of every lexical use.
