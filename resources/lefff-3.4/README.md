# Lefff 3.4 conjugation feasibility resource

Lefff by Benoît Sagot and contributors, mirrored unchanged in RosaeNLG at
commit `ff38d3275e86567142506592d6e14ce679bf70e3`.
See [provenance](provenance.json) and the original [LGPL-LR](LICENSE-LGPLLR).

The gzip file decompresses to the original complete `lefff-3.4.mlex` bytes.
Lexique's 2026-11-05 conversion selects verb rows, expands explicitly encoded
dimensions and builds read-only lookup tables. Derived data remains LGPL-LR;
Lexique's conversion code is MIT. No RosaeNLG generator code is copied or run.

Redistribution must retain attribution, license and warranty notices, identify
data modifications and their date, and license derived linguistic data under
LGPL-LR. This validation package supplies the complete corresponding legible
source and conversion code (sections 1, 2 and 4a); it contains no encrypted data.
No noncommercial restriction is present. An eventual desktop package must carry
the same materials and notices; this resource is not yet bundled in the app.

Citation: Sagot (2010), *The Lefff, a freely available and large-coverage
morphological and syntactic lexicon for French*, LREC 2010, Istanbul.
